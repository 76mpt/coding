# 009-range-add-max · 區間加值後的最大值

- 階段：競賽演算法（C++ 為主） / 3.2 前綴和與差分
- 語言：C++　難度：standard　互動方式：標準輸入 / 標準輸出
- 提示：共 4 階（`python trainer.py hint 009-range-add-max`）
- 測資：7 筆（`python trainer.py test 009-range-add-max`）

────────────────────────────────────────────────────────────────────

有一個長度為 n 的陣列，**一開始全部是 0**。

接著有 q 次操作，每次操作給三個整數 `l r v`，表示把區間 `[l, r]`（含兩端）
裡的每個位置都**加上** v。

所有操作做完後，請輸出陣列的**最大值**，以及**最先**達到這個最大值的位置（1-based）。

**輸入格式**

```
第一行：n q
接下來 q 行：每行三個整數 l r v
```

**輸出格式**

```
一行兩個整數：最大值 位置
```

**範例**

輸入：
```
5 2
1 3 2
2 5 1
```

輸出：
```
3 2
```

推導過程：
```
初始       [0, 0, 0, 0, 0]
1 3 2  →  [2, 2, 2, 0, 0]
2 5 1  →  [2, 3, 3, 1, 1]
```
最大值 3，最先出現在位置 2。

**限制**
- `1 <= n <= 2 * 10^5`
- `0 <= q <= 2 * 10^5`（q 可能是 0，此時整個陣列都是 0，答案是 `0 1`）
- `1 <= l <= r <= n`
- `1 <= v <= 100`

**效能要求**：n 和 q 都是 20 萬的大測資，並附時間上限。
每次操作老實地跑一遍 `for (i = l; i <= r; i++) a[i] += v;` 是 O(n·q) = 4×10^10，必然超時。

**提示方向**：你不需要在每次操作時就知道陣列長什麼樣子，只需要**最後**知道。
