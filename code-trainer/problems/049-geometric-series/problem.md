等比級數：每一項都是前一項乘上 `r`。

```
1 + r + r² + r³ + … + r^(n−1)
```

**有限項的閉式解：**

```
         1 − rⁿ
Sₙ  =  ─────────        （r ≠ 1）
         1 − r

Sₙ  =  n                （r = 1，全部都是 1）
```

**無窮項只在 `|r| < 1` 時收斂：**

```
S∞  =  1 / (1 − r)      （|r| < 1）
```

`|r| >= 1` 時每一項不會縮小，總和發散。

## 要實作的函式

```python
geometric(r, n)
```

回傳三個東西：

```
( 逐項累加 n 項的結果,    ← 真的用迴圈加
  閉式解 Sₙ,
  無窮和 S∞ 或 None )     ← |r| >= 1 時是 None（發散）
```

**前兩個必須用不同方法算出來**——一個逐項累加、一個套公式。
它們相等就證明你的閉式解沒記錯。

**範例**

```python
geometric(0.5, 10)
->  (1.998046875, 1.998046875, 2.0)
```

10 項加起來是 1.998，閉式解一樣，而無窮多項會收斂到 2。

```python
geometric(0.5, 1000)   ->  (2.0, 2.0, 2.0)          # 1000 項已經看不出差別
geometric(2, 10)       ->  (1023.0, 1023.0, None)   # r=2 發散
geometric(1, 5)        ->  (5.0, 5.0, None)         # r=1 每項都是 1
geometric(-0.5, 1000)  ->  (0.667, 0.667, 0.667)    # 負的 r 也會收斂，交錯著逼近
geometric(0.5, 0)      ->  (0.0, 0.0, 2.0)          # 0 項的和是 0
```

**注意 `r = 1` 的特例**：閉式解的分母 `1 − r` 會是 0，必須另外處理（答案是 `n`）。

## 為什麼 `log₂ n` 到處都是

這節還有另一個主題。「**每次砍一半，幾次會砍完？**」的答案是 `log₂ n`——
那是二分搜尋、合併排序、樹的高度、堆積操作的共同來源。

它跟等比級數是同一件事的兩面：
**「一直乘 r」的反問就是「乘幾次會到某個目標」**，而那個問題的答案是對數。

**限制**
- `r` 是 float，可以是負的、可以是 0。
- `n >= 0`，最多 10⁵。
- 判定使用近似比較，容差 10⁻⁹（大 n 時放寬）。
