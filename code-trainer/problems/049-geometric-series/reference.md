# 049-geometric-series · 等比級數與收斂條件 — 參考解

## 標準解

```python
def geometric(r, n):
    s = 0.0
    term = 1.0
    for _ in range(n):
        s += term
        term *= r              # 遞推，不要每次重算 r**k

    closed = float(n) if r == 1 else (1 - r ** n) / (1 - r)
    inf_sum = 1 / (1 - r) if abs(r) < 1 else None

    return s, closed, inf_sum
```

## 閉式解怎麼推出來的

不要背，這個推法兩行就完成，而且**同一招在很多地方都能用**：

```
Sₙ     = 1 + r + r² + … + r^(n−1)
r·Sₙ   =     r + r² + … + r^(n−1) + rⁿ
────────────────────────────────────── 相減
Sₙ − r·Sₙ = 1 − rⁿ
Sₙ(1 − r) = 1 − rⁿ
Sₙ = (1 − rⁿ) / (1 − r)
```

**乘上公比再相減，中間項全部消掉**——這叫**錯位相減**。
（`r = 1` 時最後一步除以 0，所以要另外處理，答案顯然是 n。）

無窮和：`|r| < 1` 時 `rⁿ → 0`，所以 `S∞ = 1/(1−r)`。
`|r| >= 1` 時 `rⁿ` 不會消失，級數發散。

## `term *= r` 而不是 `r ** k`

```python
for k in range(n):
    s += r ** k        # 每項都重算一次冪次

term = 1.0
for _ in range(n):
    s += term
    term *= r          # 一次乘法就得到下一項
```

**遞推比重算便宜**。而且 `r ** k` 對大 k 還會累積更多捨入誤差
（雖然 CPython 的 `**` 用快速冪，是 O(log k) 不是 O(k)，但仍然比一次乘法貴）。

這個「用上一項推出下一項」的模式在數列題裡到處都是——
**費氏數列、DP 的滾動陣列、指數移動平均**都是同一個形狀。

## 為什麼 `abs(r) < 1` 一個條件就夠

```
r = 1     每項都是 1，加到無窮 → 發散
r = -1    1, -1, 1, -1, … 部分和在 1 和 0 之間跳 → 不收斂
|r| > 1   每項越來越大 → 發散
```

**`|r| < 1` 是收斂的充要條件**，一個 `abs()` 就涵蓋了三種發散情況。

注意 `r = -1` 那個：部分和**有界**但**不收斂**——它在 1 和 0 之間永遠震盪。
「有界」和「收斂」是兩回事，這是分析學的第一個重要區分。

## 這條式子在你的路線圖上

等比級數看起來像高中數學，但它是**收斂性分析的基本工具**：

| 節點 | 用在哪 |
|---|---|
| **M1.2** 梯度下降收斂性 | 誤差每步乘上一個 `< 1` 的因子 → `‖eₖ‖ ≤ ρᵏ‖e₀‖`，**線性收斂就是等比級數** |
| **M1.8** 共軛梯度 | 收斂速度用條件數表示的等比因子 |
| **M2.10** 卡爾曼濾波 | 誤差共變異的穩態解 |
| **M5.2** 馬可夫鏈 | 收斂到平穩分布的速度由第二大特徵值決定，形式就是 `λ₂ᵏ` |
| **強化學習** | 折扣報酬 `Σ γᵏ rₖ`，`γ < 1` 保證它收斂——**那就是這條式子** |

**「線性收斂」這個詞的意思就是「誤差構成等比數列」**。
你之後讀論文看到 `O(ρᵏ)` 的收斂率，講的都是這件事。

## `log₂ n` 為什麼是「砍一半的次數」

這節的另一個主題，跟等比級數是同一枚硬幣的兩面：

```
等比：一直乘 r，第 k 項是 rᵏ
對數：乘幾次會到目標？   →  k = log_r(目標)
```

「n 個元素每次砍一半，幾次剩 1 個？」

```
n → n/2 → n/4 → … → 1
```

砍 k 次剩 `n/2ᵏ`，令它等於 1 得 `k = log₂ n`。

**這就是為什麼這些東西都是 O(log n)：**

| 演算法 | 為什麼 log |
|---|---|
| 二分搜尋 | 每次排除一半 |
| 平衡樹的高度 | 每層節點數翻倍 |
| 堆積的 sift-up/down | 沿著樹高走 |
| 合併排序的層數 | 每層切一半（總成本 n log n） |

`log₂(10⁶) ≈ 20`——**一百萬個元素，二分搜尋只要 20 步**。
這個數字直覺值得記住，它是「為什麼 O(log n) 幾乎等於免費」的來源。

## 常見錯誤

1. **`r == 1` 沒特判** —— `(1 - 1**n) / (1 - 1)` 是 `0/0` → `ZeroDivisionError`。
2. **無窮和的條件寫成 `r < 1`** —— 漏掉負數：`r = -2` 也會 `< 1`，但它發散。要用 `abs(r) < 1`。
3. **`r = -1` 判成收斂** —— `abs(-1) < 1` 是 False，寫對就自然排除了。
4. **用 `r ** k` 逐項算** —— 會過，但大測資慢。
5. **`n = 0` 時特判** —— 不用。迴圈不跑得 0，閉式 `(1 - r⁰)/(1-r) = 0`，兩者本來就一致。
6. **回傳 0 而不是 None** —— 發散時要 `None`。「發散」和「和是 0」是不同的事。
