# 046-bayes-posterior · 貝氏定理與偽陽性

- 階段：前置：高中數學重補（公式與計算流利度） / M00.6 機率、期望值與貝氏
- 語言：Python　難度：warmup　互動方式：實作函式
- 要實作的入口：`posterior`
- 提示：共 4 階（`python trainer.py hint 046-bayes-posterior`）
- 測資：10 筆（`python trainer.py test 046-bayes-posterior`）

────────────────────────────────────────────────────────────────────

有一種疾病，**盛行率 1%**。檢驗的準確度很高：

- **敏感度 99%**：有病的人，99% 會被驗出陽性
- **特異度 99%**：沒病的人，99% 會被驗出陰性

**你驗出陽性。你真的有病的機率是多少？**

直覺會說 99%。**正確答案是 50%。**

## 為什麼

假設 10000 個人：

```
有病 100 人      →  驗出陽性 99 人      （真陽性）
沒病 9900 人     →  驗出陽性 99 人      （偽陽性，1% 的 9900）
                    ─────────────────
                    陽性共 198 人，其中真的有病的只有 99 人  →  50%
```

**因為沒病的人太多了**，即使偽陽性率只有 1%，絕對數量還是跟真陽性一樣多。

這叫**基本率謬誤（base rate fallacy）**——人的直覺會忽略盛行率。

## 貝氏定理

```
           P(陽性|有病) · P(有病)
P(有病|陽性) = ──────────────────────────
                    P(陽性)

P(陽性) = P(陽性|有病)·P(有病) + P(陽性|沒病)·P(沒病)
        = 敏感度 · prior      + (1 − 特異度) · (1 − prior)
```

## 要實作的函式

```python
posterior(prior, sensitivity, specificity)
```

回傳「驗出陽性的條件下，真的有病」的機率。

**範例**

```python
posterior(0.01, 0.99, 0.99)    ->  0.5                     # 上面那個例子
posterior(0.001, 0.99, 0.95)   ->  0.019434628975265003    # 盛行率更低 → 只有 2%
posterior(0.5, 0.9, 0.9)       ->  0.9                     # 盛行率 50% 時直覺才對
posterior(0.1, 1.0, 0.0)       ->  0.1                     # 完全沒鑑別力的檢驗
```

**最後一個值得看**：敏感度 100%、特異度 0% 代表「**不管有沒有病都驗出陽性**」——
這種檢驗完全沒有資訊量，所以後驗機率**等於先驗機率**，什麼都沒學到。

**錯誤處理**

分母 `P(陽性)` 為 0 時（沒有任何人會驗出陽性）→ `raise ValueError`。

**限制**
- 三個參數都在 `[0, 1]`。
- 判定使用近似比較，容差 10⁻⁹。
