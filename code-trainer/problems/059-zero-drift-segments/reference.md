# 059-zero-drift-segments · 淨位移剛好是 k 的片段 — 參考解

## 標準解

```python
def count_segments(deltas, k):
    seen = {0: 1}                            # 前綴和 → 出現次數；0 代表空前綴
    total = 0
    count = 0
    for d in deltas:
        total += d                           # 目前的前綴和 P[j]
        count += seen.get(total - k, 0)      # 先查：有幾個 i 使 P[i] = P[j] − k
        seen[total] = seen.get(total, 0) + 1 # 再放
    return count
```

時間 O(n)（平均），空間 O(n)。

這是 LeetCode 560，面試高頻題，也是雜湊表最有代表性的應用之一。

## 為什麼是對的

定義前綴和 `P[0] = 0`、`P[j] = deltas[0] + … + deltas[j−1]`。
片段 `deltas[i..j−1]`（`0 <= i < j <= n`）的和是 `P[j] − P[i]`。

所以答案 = 滿足 `P[j] − P[i] = k`、`i < j` 的配對數。

固定 j，合法的 i 就是「前面所有 `P[i] = P[j] − k` 的位置」，個數就是 `seen[P[j] − k]`——
只要 `seen` 裡恰好存了 `P[0] … P[j−1]` 每個值的出現次數。

迴圈的不變量正是這件事：
- 進迴圈前 `seen` 只有 `P[0] = 0` → `{0: 1}`
- 處理 j 時先查（此時 seen 裡是 `P[0..j−1]`），再把 `P[j]` 放進去

把每個 j 的配對數加起來，就是總數。

## 三題放在一起看

| 題目 | 問什麼 | 元素 | 工具 |
|---|---|---|---|
| 054 | 和 ≥ target 的**最短**區間 | **非負** | 滑動視窗，O(1) 空間 |
| 056 | 和 = target 的**一對元素** | 任意 | dict 存位置 |
| 這題 | 和 = k 的**區間個數** | **任意** | 前綴和 + dict 存次數 |

**為什麼這題不能用滑動視窗？** 看 `[-1, -1, 1]`、k = 0。
滑動視窗從 `[-1]` 開始，和是 -1 < 0，所以擴張右界；`[-1, -1]` 是 -2，更小，繼續擴；
`[-1, -1, 1]` 是 -1，還是不到，右界已經到底——結束，答案 0。
但 `[-1, 1]`（位置 1-2）的和是 0，正確答案是 1。

滑動視窗的前提是「擴張讓和變大、收縮讓和變小」。負數打破了這個單調性，
你沒辦法根據「現在的和太大還是太小」決定該動哪一邊。
前綴和 + 雜湊不依賴單調性，所以正負都能處理，代價是 O(n) 的空間。

## 常見錯誤

1. **忘了 `{0: 1}`**——從索引 0 開始的片段全部漏掉。`[1, 2, 3]`、k = 3 會回 1 而不是 2。

2. **先放再查**——k = 0 時每個位置都配到自己，把長度 0 的空片段算進去。
   `[5]`、k = 0 會回 1 而不是 0；`[0, 0, 0]` 會回 9 而不是 6。

3. **硬套滑動視窗**——正數測資全過，負數測資錯。這是最危險的錯，因為範例前兩個看起來都能過。

4. **dict 存位置而不是次數**——`seen[total] = j` 會蓋掉前面同樣前綴和的位置，
   `[0, 0, 0]` 這種前綴和一直重複的情況會嚴重少算。

5. **存 list of 前綴和，用 `list.count()` 查**——邏輯正確但每次查詢 O(n)，整體 O(n²)，大測資超時。

## 延伸

**前綴和推廣到二維，就是 CV 最經典的資料結構之一：積分影像（integral image）**。

```
I[y][x] = 所有 (y' < y, x' < x) 的像素總和
任意矩形區域的和 = I[y2][x2] − I[y1][x2] − I[y2][x1] + I[y1][x1]
```

四次查表就能算出任意大小矩形的像素和，O(1)。
**Viola–Jones 人臉偵測（2001）** 能在當年的硬體上即時跑，就是靠這個——
它要在每個位置、每個尺度算上萬個矩形特徵，沒有積分影像根本不可能。
SURF 特徵點也用同樣的技巧近似 Hessian 的盒狀濾波。

其他延伸題：
- LeetCode 974：和能被 k 整除的子陣列——dict 的 key 改成 `total % k`
- LeetCode 525：0 和 1 個數相同的最長子陣列——把 0 當 -1，找和為 0 的**最長**片段，dict 改存**第一次出現的位置**
