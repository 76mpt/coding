# 056-pair-to-target · 湊出目標批次大小

- 階段：資料結構與演算法（LeetCode 風格） / 2.2 雜湊表
- 語言：Python　難度：warmup　互動方式：實作函式
- 要實作的入口：`find_pair`
- 提示：共 4 階（`python trainer.py hint 056-pair-to-target`）
- 測資：11 筆（`python trainer.py test 056-pair-to-target`）

────────────────────────────────────────────────────────────────────

訓練模型時你想把兩個資料分片合併成一個批次，而批次大小必須剛好是 `target`。

給一個整數陣列 `sizes`（每個分片的樣本數，**沒有排序**）和一個整數 `target`，
找出兩個**不同位置**的分片，大小加起來剛好等於 `target`。

實作 `find_pair(sizes, target)`，回傳這兩個位置 `(i, j)`，且 `i < j`。
如果有很多組答案，回傳 **`j` 最小**的那一組；`j` 一樣時回傳 **`i` 最小**的那一組。
找不到就回傳 `None`。

**範例**

```python
find_pair([2, 7, 11, 15], 9)      ->  (0, 1)     # 2 + 7
find_pair([3, 2, 4], 6)           ->  (1, 2)     # 2 + 4；不能用 3 + 3，同一個位置不能用兩次
find_pair([3, 3], 6)              ->  (0, 1)     # 兩個不同位置剛好都是 3，可以
find_pair([1, 2, 3], 100)         ->  None
```

「`j` 最小」的意思是：**從左往右掃，最早能湊成一對的那個時刻**。

```python
find_pair([1, 4, 3, 2, 5], 5)     ->  (0, 1)
```

加起來是 5 的配對有 `(0, 1)` 是 1+4、`(2, 3)` 是 3+2。
`(0, 1)` 的 `j` 是 1，比 `(2, 3)` 的 3 小，所以答案是 `(0, 1)`。

**限制**
- `0 <= n <= 2 * 10^5`
- `-10^9 <= sizes[i], target <= 10^9`（題目包裝成樣本數，但測資會有負數和 0）
- 回傳 tuple `(i, j)` 或 `None`

**效能要求**：測資裡有一筆 n = 200,000 的大測資與時間上限。
兩層迴圈枚舉所有配對是 O(n²) ≈ 2×10^10 次運算，必然超時。

陣列**沒有排序**，所以上一個節點的對撞指標不能直接用（排序會打亂位置）。
這題要你用 **dict** 把 O(n²) 降到 O(n)。
