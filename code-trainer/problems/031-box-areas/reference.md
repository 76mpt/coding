# 031-box-areas · 篩選偵測框的面積 — 參考解

## 標準解

```python
def box_areas(boxes, min_area=0):
    return [(x2 - x1) * (y2 - y1)
            for x1, y1, x2, y2 in boxes
            if (x2 - x1) * (y2 - y1) >= min_area]
```

對照它取代掉的迴圈版：

```python
def box_areas(boxes, min_area=0):
    result = []
    for x1, y1, x2, y2 in boxes:          # ← 中間那行，原封不動
        area = (x2 - x1) * (y2 - y1)
        if area >= min_area:              # ← 最後那行，原封不動
            result.append(area)           # ← 第一行，append 的內容
    return result
```

**comprehension 不是新語法，是同一個迴圈換個排版。** 三個部位一一對應，只是把 `append` 的東西提到最前面、省掉建空 list 和 `return`。

### `for x1, y1, x2, y2 in boxes` 的解包

每個元素是 4 個數字的序列，`for` 可以直接把它拆成四個名字。這比 `box[0]`、`box[1]` 好在**名字說明了語意**——讀的人不用去數第幾格是什麼。

如果框的格式改成 `(x, y, w, h)`，你只要改這一行的名字，下面的算式跟著改；用索引的話得回頭數。

## 面積算了兩次

標準解有個瑕疵：`(x2-x1)*(y2-y1)` 出現兩遍，**每個框都算兩次**。

這是 comprehension 的先天限制——**過濾條件看不到前面算好的值**，因為它們是同一個運算式的不同部位，沒有地方放中間變數。

Python 3.8 加了**海象運算子** `:=` 解決這件事：

```python
def box_areas(boxes, min_area=0):
    return [area
            for x1, y1, x2, y2 in boxes
            if (area := (x2 - x1) * (y2 - y1)) >= min_area]
```

`(area := 算式)` 做兩件事：**把值存進 `area`，同時把值交給外面的比較**。所以過濾時算一次、存起來，前面直接用那個名字。

注意順序：`if` 在 Python 的求值中**先於**產出的運算式執行，所以 `area` 在被用到時已經有值了。

> 還記得你在 002-collatz 寫錯三元運算式時，Python 建議「Maybe you meant `:=`」嗎？就是這個運算子。它存在的理由正是「**我想在運算式中間賦值**」——而 comprehension 的過濾條件是它最常見的用途。

**要不要用**：這題規模小、算式簡單，兩種都可以。算式很貴（例如呼叫一個慢函式）或很長時，`:=` 就值得。但**不要為了炫技而用**——多數人第一次看到會卡一下。

## 什麼時候不該壓成 comprehension

節點 1.6 的學習目標是「能把三層迴圈壓成一行**可讀的** comprehension，**也知道何時不該壓**」。判準：

| 情況 | 建議 |
|---|---|
| 一個轉換 + 一個過濾 | ✅ comprehension |
| 巢狀兩層、而且好懂（座標網格） | ✅ 可以 |
| 巢狀三層以上 | ❌ 用迴圈 |
| 迴圈體裡要做好幾件事（記 log、更新多個變數） | ❌ 用迴圈 |
| 需要 try/except | ❌ comprehension 裡不能寫 |
| 條件超過兩個、或有 if/elif/else 分支 | ❌ 讀不動 |

**能壓成一行不代表該壓。** 判準是「讀的人要不要看兩遍」。

## 複雜度

時間 **O(n)**、空間 **O(k)**（k 是通過過濾的數量）。這是最佳解。

順帶：如果呼叫端只想走訪一次、不需要留著整個 list，把中括號換成小括號就變成 **generator expression**，空間降到 O(1)。你在 021、025 用過，021 的 review 裡我實測過 10⁵ 個元素差 3700 倍記憶體。

## 常見錯誤

1. **`>` 寫成 `>=`（或反過來）** —— 題目說「面積 ≥ min_area」。測資 `[(0,0,3,3),(0,0,3,3)]` 配 `min_area=9` 專門抓這個，面積剛好等於門檻要保留。
2. **忘記 `min_area=0` 的預設值** —— 第二筆測資只給一個參數。
3. **以為面積 0 的框該被濾掉** —— `0 >= 0` 是 True，預設情況要保留。「空框」在真實偵測輸出裡確實會出現（模型吐出退化的框），要不要濾掉是呼叫者的決定，不是這個函式的。
4. **回傳前排序** —— 題目要原順序。隱藏測資會抓。
5. **`if` 放錯位置** —— `[x if cond else y for ...]` 是**條件運算式**（決定每個元素變成什麼，必須有 else），`[x for ... if cond]` 才是**過濾**（決定要不要這個元素，不能有 else）。你在 003-apply-discount 把這兩個混在一起過。
6. **用 `box[0]`、`box[1]` 而不解包** —— 會過，但可讀性差很多。
