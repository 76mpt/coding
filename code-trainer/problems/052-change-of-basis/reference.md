# 052-change-of-basis · 換一組基底看同一個變換 — 參考解

## 標準解

```python
def change_of_basis(basis, points, matrix):
    b1, b2 = basis
    # 基底向量當「行」排進 B：B 把 B-座標翻成標準座標
    B = [[float(b1[0]), float(b2[0])],
         [float(b1[1]), float(b2[1])]]
    det = B[0][0] * B[1][1] - B[0][1] * B[1][0]
    Binv = [[B[1][1] / det, -B[0][1] / det],
            [-B[1][0] / det, B[0][0] / det]]

    def apply(M, p):
        return [M[0][0] * p[0] + M[0][1] * p[1],
                M[1][0] * p[0] + M[1][1] * p[1]]

    def matmul(X, Y):
        c1 = apply(X, apply(Y, [1.0, 0.0]))
        c2 = apply(X, apply(Y, [0.0, 1.0]))
        return [[c1[0], c2[0]], [c1[1], c2[1]]]

    coords = [apply(Binv, p) for p in points]
    rebuilt = [apply(B, c) for c in coords]
    T_B = matmul(matmul(Binv, matrix), B)
    moved = [apply(Binv, apply(matrix, p)) for p in points]
    return coords, rebuilt, T_B, moved
```

## 為什麼 B 是「基底向量當行」

這是全題最容易錯的一點，值得推一次。

B 該做的事是「吃 B-座標，吐標準座標」。把 `c = (1, 0)` 餵進去——
`(1,0)` 在 B-座標的意思是「一份 b₁、零份 b₂」，也就是 b₁ 本身。所以

```
B (1,0) = b₁
```

而 `B (1,0)` 就是 B 的**第一行**。所以第一行必須是 b₁，第二行同理是 b₂。

這跟上一題「乘積的第 j 行 = e_j 的像」是同一個原理：
**要知道矩陣的某一行，就把對應的基向量餵進去。**

寫成 `[[b1x, b1y], [b2x, b2y]]`（當「列」放）是最常見的 bug，
那是正確答案的轉置，只有基底剛好對稱時才會意外通過。

## 為什麼是 `B⁻¹ M B` 而不是 `B M B⁻¹`

由右往左讀，跟函式合成一樣。`[T]_B` 要「吃 B-座標，吐 B-座標」：

```
     c  ──B──▶  標準座標  ──M──▶  變換後的標準座標  ──B⁻¹──▶  變換後的 B-座標
  (B-座標)
```

接起來就是 `B⁻¹ M B`。反過來寫 `B M B⁻¹` 是「吃標準座標、吐標準座標，
但中間跑去 B 的世界繞一圈」——另一個變換，通常不等於 M。

這種 `P⁻¹ M P` 叫**相似變換**（similarity transform）。
兩個矩陣差一個相似變換，就說它們**相似**——它們是同一個變換的兩種寫法。

相似矩陣共享很多東西：**行列式、跡（trace）、特徵值、秩**全都一樣，
因為那些量描述的是變換本身，跟你用哪把尺無關。
拿範例驗一下：`[[2,0],[0,3]]` 和 `[[2.5,-0.5],[-0.5,2.5]]`，
行列式都是 6，跡都是 5。

## 複雜度

- 建 `B`、`Binv`、`T_B`：常數時間（固定 2×2）
- 三個串列各 O(n)，整體 O(n)，空間 O(n)

**`T_B` 只算一次，不是每個點算一次。** 跟上一題「先把矩陣乘起來再套到所有點」
是同一個模式：把與資料無關的計算提到迴圈外。

對 2×2 用閉式反矩陣是對的，但**矩陣一大就不要求反矩陣**——數值不穩且慢。
實務要解 `B c = p` 會用 `np.linalg.solve(B, p)` 而不是 `inv(B) @ p`。
這件事你在 M0.6 條件數會付出代價才真正記住。

## 常見錯誤

1. **B 的行列放反**——寫成 `[[b1x, b1y], [b2x, b2y]]`。
   徵兆是第二個回傳值跟原本的點對不上。
   對稱基底（例如 `[[1,1],[1,-1]]`）測不出來，非對稱的（`[[1,2],[3,4]]`）才抓得到。

2. **三連乘寫成 `B M B⁻¹`**——前兩個回傳值都正確（沒用到 T_B），只有第三、四個錯。
   M 跟 B 可交換時還會意外通過，所以測資裡放了剪切矩陣。

3. **`matmul` 忘了轉置**——跟上一題同一個坑。

4. **除以 `det` 時只除了主對角線**——四個元素都要除。
   徵兆是組回來的點差一個固定倍數。

5. **第四個回傳值用 `[T]_B` 作用在第一個上算出來**——這樣就沒驗證到任何事，
   等於在說「我算的等於我算的」。要照「先 M 再換座標」獨立算一次。

6. **`points` 是空串列時報錯**——用 list comprehension 就自動處理了，
   但如果先取 `points[0]` 決定什麼就會 IndexError。

## 延伸

座標變換是 3D 視覺的日常語言，之後每天都會用到：

- **M0.4 特徵向量**：基底選成特徵向量，`[T]_B` 會變成**對角矩陣**。
  「對角化」的全部意義就是「換一組基底，讓這個變換變簡單」。
- **M0.5 SVD**：輸入端一組基底、輸出端一組，讓任何矩陣都變對角。
- **M2.1 相機模型**：世界座標 → 相機座標就是一次基底變換，`X_cam = R (X_world − t)`。
- **M2.8 李群**：`R' = R₂ R₁ R₂ᵀ` 是把旋轉「換到另一個座標系來看」，
  跟這題的 `B⁻¹ M B` 是同一件事（正交矩陣的反矩陣就是轉置）。
- **M4.5 PCA**：找一組基底讓資料的協方差矩陣對角化。

下一個節點 M0.2 會問「這些行向量張成了什麼空間」，並要你手寫 Gram-Schmidt
把任意基底變成**正交**基底——正交基底的好處就是 `B⁻¹` 直接等於 `Bᵀ`，不用除行列式。
