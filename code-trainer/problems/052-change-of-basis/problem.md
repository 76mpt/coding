# 052-change-of-basis · 換一組基底看同一個變換

────────────────────────────────────────────────────────────────────

上一題你看到「合成變換就是矩陣相乘」。這題問一個更根本的問題：
**同一個變換，換一把尺來量，會長成什麼樣？**

你寫的 `(3, 4)` 其實省略了一句話——「以標準基底 e₁=(1,0)、e₂=(0,1) 來看」。
完整寫法是 `p = 3·e₁ + 4·e₂`。換一組基底 `b₁`、`b₂`，同一個點就有不同的數字：

```
p = c₁·b₁ + c₂·b₂
```

`(c₁, c₂)` 是 p **在基底 B 之下的座標**。點沒有動，動的是描述它的尺規。
這在 CV 裡就是「同一個 3D 點，在世界座標系和相機座標系有不同的數字」。

變換本身也會換樣子。把基底向量當成**行**排起來：

```
B = [[b₁ₓ, b₂ₓ],
     [b₁ᵧ, b₂ᵧ]]
```

這個 B 的作用是「吃 B-座標，吐標準座標」。那麼標準基底下的變換 M，
換到 B 之下就是 `[T]_B = B⁻¹ M B`——由右往左讀：`B` 把 B-座標翻成標準座標，
`M` 做事，`B⁻¹` 再翻回 B-座標。

實作 `change_of_basis(basis, points, matrix)`，回傳一個 tuple，四個元素：

```
( 每個點的 B-座標,               ← 解 B c = p
  用 c₁·b₁ + c₂·b₂ 組回來的點,   ← 應該還原成原本的點
  [T]_B = B⁻¹ M B 這個 2x2 矩陣,
  變換後的點的 B-座標 )          ← 先用 M 變換，再換算成 B-座標
```

`basis` 是 `[b1, b2]`、每個是 `[x, y]`，**保證線性獨立**（行列式不為 0）；
`points` 是標準座標的點串列；`matrix` 是標準基底下的 M。所有數值回傳 float。

**範例**

```python
basis  = [[1, 1], [1, -1]]     # b₁=(1,1)、b₂=(1,-1)
points = [[2, 0]]
matrix = [[2, 0], [0, 3]]      # x 拉 2 倍、y 拉 3 倍

change_of_basis(basis, points, matrix)
# -> ( [[1.0, 1.0]],                    (2,0) = 1·b₁ + 1·b₂
#      [[2.0, 0.0]],                    組回來就是原本的點
#      [[2.5, -0.5], [-0.5, 2.5]],      [T]_B
#      [[2.0, 2.0]] )                   M(2,0)=(4,0)，換算成 B-座標是 (2,2)
```

注意第三個回傳值跟原本的對角矩陣長得完全不同，但它們是**同一個變換**。

## 這題真正要你看到的東西

把 `[T]_B` 作用在第一個回傳值上，會得到第四個回傳值。也就是說這兩條路殊途同歸：

```
點 ──M──▶ 變換後的點 ──換座標──▶ 結果
點 ──換座標──▶ B-座標 ──[T]_B──▶ 結果
```

矩陣長得不一樣，做的事情是同一件。
**矩陣描述的是變換在某把尺下的樣子，不是變換本身。**

`P⁻¹ M P` 這種形式叫**相似變換**。相似的兩個矩陣共享行列式、跡、特徵值、秩——
因為那些量描述的是變換本身，跟你用哪把尺無關。
拿範例驗一下：`[[2,0],[0,3]]` 和 `[[2.5,-0.5],[-0.5,2.5]]`，行列式都是 6，跡都是 5。

**限制**
- 固定 2×2、二維，元素可能是負數或浮點數。
- `basis` 保證線性獨立，不用處理不可逆的情況。
- `points` 可能是空串列，這時第一、二、四個都是 `[]`，矩陣照算。
- **不要用 numpy**，反矩陣自己算（2×2 有閉式解，見提示）。
- 第四個**要照「先變換再換座標」獨立算**，不要拿 `[T]_B` 套第一個回傳值——
  那兩條路徑相等正是要驗證的事，自己抄自己就什麼都沒驗到（隱藏測資會抓）。
