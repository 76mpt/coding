## 背景

你平常寫的座標 `(3, 4)` 其實是省略了一句話：**「以標準基底 e₁=(1,0)、e₂=(0,1) 來看」**。
寫成完整的樣子是

```
p = 3·e₁ + 4·e₂
```

換一組基底 `b₁`、`b₂`，同一個點就有不同的座標：

```
p = c₁·b₁ + c₂·b₂
```

`(c₁, c₂)` 就是 p **在基底 B 之下的座標**。點沒有動，動的是描述它的尺規。

這件事在 CV 裡就是「同一個 3D 點，在世界座標系和相機座標系有不同的數字」。

## 第二層：變換本身也換了樣子

一個線性變換 T 在標準基底下是矩陣 `M`。換到基底 B 之下，它會變成另一個矩陣 `[T]_B`：

```
[T]_B = B⁻¹ · M · B
```

其中 `B` 是**把基底向量當成「行」排起來**的矩陣：

```
B = [[b₁ₓ, b₂ₓ],
     [b₁ᵧ, b₂ᵧ]]
```

讀法是由右往左：`B` 把 B-座標翻成標準座標 → `M` 在標準座標裡做事 → `B⁻¹` 翻回 B-座標。

## 要實作的函式

```python
def basis_report(basis, points, matrix):
```

- `basis`：兩個基底向量 `[b1, b2]`，每個是 `[x, y]`。**保證線性獨立**（行列式不為 0）
- `points`：點的串列，每個是 `[x, y]`，用標準座標給的
- `matrix`：2×2 矩陣 `[[a, b], [c, d]]`，標準基底下的變換 M

回傳 dict：

| 鍵 | 型別 | 內容 |
|---|---|---|
| `"coords"` | list | 每個點在基底 B 之下的座標 `[c₁, c₂]` |
| `"rebuilt"` | list | 用 `c₁·b₁ + c₂·b₂` 把點組回來（應該等於原本的點） |
| `"matrix_in_basis"` | list | `[T]_B = B⁻¹ M B`，2×2 |
| `"consistent"` | bool | 見下方說明 |

`consistent` 要驗證的是**這兩條路殊途同歸**（容差 `1e-9`）：

```
路線一：點 → 用 M 變換 → 換算成 B-座標
路線二：點 → 換算成 B-座標 → 用 [T]_B 變換
```

全部的點兩條路都一致才是 `True`。

所有數值回傳 `float`。

## 範例

```python
basis  = [[1, 1], [1, -1]]     # b₁=(1,1), b₂=(1,-1)
points = [[2, 0]]
matrix = [[2, 0], [0, 3]]      # x 方向拉 2 倍、y 方向拉 3 倍
```

`(2,0) = 1·(1,1) + 1·(1,-1)`，所以 B-座標是 `(1, 1)`。

```python
{
  "coords":          [[1.0, 1.0]],
  "rebuilt":         [[2.0, 0.0]],
  "matrix_in_basis": [[2.5, -0.5], [-0.5, 2.5]],
  "consistent": True
}
```

注意 `matrix_in_basis` 長得跟原本的對角矩陣完全不同，但它們是**同一個變換**。
檢查一下：`[T]_B` 作用在 `(1,1)` 上得到 `(2, 2)`；而 M 作用在 `(2,0)` 上得到 `(4, 0)`，
換算成 B-座標正是 `(2, 2)`。兩條路一致。

## 限制

- 固定 2×2、二維
- `basis` 保證線性獨立，不用處理不可逆的情況
- `points` 可能是空串列，這時 `coords`、`rebuilt` 都是 `[]`，`consistent` 是 `True`
- 元素可能是負數或浮點數
- **不要用 numpy**，反矩陣自己算（2×2 有閉式解，見提示）
- 浮點數比較一律用容差 `1e-9`

## 你應該親眼看到的事

`consistent` 永遠是 `True`。矩陣長得不一樣，做的事情是同一件——
**矩陣描述的是變換在某組尺規下的樣子，不是變換本身。**
