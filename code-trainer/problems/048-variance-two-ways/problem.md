# 048-variance-two-ways · 變異數的兩種公式

- 階段：前置：高中數學重補（公式與計算流利度） / M00.6 機率、期望值與貝氏
- 語言：Python　難度：standard　互動方式：實作函式
- 要實作的入口：`variance_two_ways`
- 提示：共 4 階（`python trainer.py hint 048-variance-two-ways`）
- 測資：10 筆（`python trainer.py test 048-variance-two-ways`）

────────────────────────────────────────────────────────────────────

變異數有兩條等價的公式：

```
定義式    Var(X) = E[(X − μ)²]  =  (1/n) Σ (xᵢ − μ)²
展開式    Var(X) = E[X²] − (E[X])²  =  (1/n) Σ xᵢ²  −  μ²
```

**數學上完全相等**（展開 `(x−μ)²` 就能推出來）。
**浮點數下不是。**

實作 `variance_two_ways(xs)`，回傳 `(定義式算的, 展開式算的)`。

- `μ` 是平均值 `sum(xs) / n`
- 用**母體變異數**（除以 `n`，不是 `n−1`）
- 空 list → `raise ValueError`

**範例**

```python
variance_two_ways([1, 2, 3, 4])   ->  (1.25, 1.25)          # 兩者一致
variance_two_ways([1, 1, 1])      ->  (0.0, 0.0)            # 沒有變異
```

## 這題真正要你看到的東西

```python
variance_two_ways([1e8, 1e8 + 1, 1e8 + 2])
->  (0.6666666666666666, 2.0)
```

**正確答案是 2/3。展開式給出 2.0——錯了三倍。**

三個數只差 1 和 2，變異數當然很小。但展開式要算：

```
E[X²] ≈ 1.0000000200000002e+16
(E[X])² ≈ 1.0000000200000000e+16
相減   → 剩下的位數全是雜訊
```

**兩個幾乎相同的大數相減，有效位數被吃光了。**
這叫**災難性抵消（catastrophic cancellation）**——float64 只有約 16 位有效位數，
兩個 16 位的數相減之後只剩下 1 位是真的。

定義式先減掉 `μ`，處理的是 `0, 1, 2` 這種小數字，完全沒有這個問題。

> **展開式在紙上比較好算（只要掃一遍），在電腦上卻可能完全錯。**
> 這就是「數值穩定性」——同一條數學式，不同的計算順序有不同的可靠度。

**限制**
- `xs` 是數字 list，可能有負數、很大或很小的值。
- 最多 10⁵ 個元素。
- 兩個回傳值都是 float。
- **兩個都要照各自的公式算**，不要偷懶回傳兩份相同的值（隱藏測資會抓）。
