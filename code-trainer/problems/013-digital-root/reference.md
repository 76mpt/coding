# 013-digital-root · 數位根與迭代次數 — 參考解

## 標準解

```python
def digital_root(n: int) -> tuple[int, int]:
    rounds = 0
    while n >= 10:
        n = sum(int(ch) for ch in str(n))
        rounds += 1
    return n, rounds
```

## 不用字串的版本

```python
def digital_root(n: int) -> tuple[int, int]:
    rounds = 0
    while n >= 10:
        total = 0
        while n > 0:
            total += n % 10       # 取最後一位
            n //= 10              # 砍掉最後一位
        n = total
        rounds += 1
    return n, rounds
```

這是**真正的巢狀迴圈**版本。C++ 沒有方便的字串轉換，通常就這樣寫。
兩個版本速度差不多（字串版在 CPython 裡其實常常更快，因為 `str()` 是 C 實作）。

**「取最後一位 + 砍掉最後一位」是拆數字的萬用手法**，記住它。

## 複雜度

設 n 有 d 位數（`d ≈ log₁₀ n`）：

- 第一輪相加最多得到 `9d`（全部是 9 的情況）
- `n ≤ 10¹⁸` 時 d ≤ 19，第一輪後最多 171（三位數）
- 第二輪後最多 `1+7+1 = 9`（一位數）

所以**輪數最多 3**，跟 n 的大小幾乎無關。時間 O(d) = O(log n)，空間 O(1)。

## 最佳解：O(1) 的數學解

數位根有一個閉式公式：

```python
def digital_root_fast(n: int) -> int:
    return 0 if n == 0 else 1 + (n - 1) % 9
```

**為什麼？** 因為 `10 ≡ 1 (mod 9)`，所以 `10ᵏ ≡ 1 (mod 9)`，
於是任何數字對 9 取餘數，等於它各位數字和對 9 取餘數：

```
1234 = 1×1000 + 2×100 + 3×10 + 4
     ≡ 1×1    + 2×1   + 3×1  + 4   (mod 9)
     = 10 ≡ 1 (mod 9)
```

「各位數字相加」這個操作**不改變 mod 9 的值**，所以數位根就是 `n mod 9`
（只是 9 的倍數要對應到 9 而不是 0，所以寫成 `1 + (n-1) % 9`）。

⚠️ **但這題不能只用公式**，因為題目還要**輪數**，那沒有閉式解，一定要真的迭代。
不過這個 mod 9 的性質本身很有用——「棄九驗算法」就是靠它檢查加法有沒有算錯。

## 常見錯誤

1. **`rounds` 從 1 開始，或初始值搞錯** — `digital_root(9)` 應該是 `(9, 0)`。
   一位數的測資就是在抓這個。
2. **迴圈條件寫成 `while n > 10`** — 那 `n = 10` 會直接跳出，回傳 `(10, 0)`，
   但 10 不是一位數。要用 `>=`。
3. **內層迴圈用了 `n` 當計數器卻沒存回去** — 做法 B 裡如果直接改 `n`，
   拆完之後 `n` 變成 0 了，要用另一個變數 `m` 或先存 `total`。
4. **忘記 `n = 0` 的情況** — 用做法 B 時 `while m > 0` 對 m=0 一次都不跑，
   `total` 是 0，剛好對。但如果寫成 do-while 風格就要小心。
5. **回傳字串而不是 int** — `sum(str(n))` 會 TypeError，
   必須 `int(ch)` 轉換。

## 延伸

這題的「反覆套用同一個操作直到穩定」模式叫做**不動點迭代（fixed-point iteration）**，
在數值方法裡是一整個大家族：

- 牛頓法求根：反覆 `x = x - f(x)/f'(x)` 直到收斂
- PageRank：反覆乘轉移矩陣直到向量不再變化
- k-means：反覆「指派 → 更新中心」直到不動
- **Diffusion 的取樣**：反覆去噪直到還原（節點 M5.6）

它們的共同結構都是「`while 還沒穩定: 更新`」，差別只在「更新」是什麼、「穩定」怎麼判斷。
你在 M0.4 手寫冪迭代求特徵值時會再看到一次。
