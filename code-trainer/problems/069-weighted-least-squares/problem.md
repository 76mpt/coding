# 069-weighted-least-squares · 加權最小平方與過定方程組

- 階段：數學基礎（Tier 0：沒有就寸步難行） / M0.3 投影與最小平方
- 語言：Python　難度：challenge　互動方式：實作函式
- 要實作的入口：`weighted_lstsq`
- 提示：共 4 階（`python trainer.py hint 069-weighted-least-squares`）
- 測資：11 筆（`python trainer.py test 069-weighted-least-squares`）

────────────────────────────────────────────────────────────────────

066 你解的是一條直線：兩個未知數、m 條方程式。
這題推到一般情況——**n 個未知數、m 條方程式，而且每條方程式的可信度不一樣**。

`A` 是 m×n 的矩陣（m ≥ n），`b` 有 m 個分量。
m > n 時 `A x = b` 通常解不出來（過定方程組），
退一步求殘差平方和最小的 x，就是 066 做的事。

這題多一件事：每條方程式配一個**正的權重** `wᵢ`。
量測來自不同的感測器：雷射測距的誤差一公分，輪速計的誤差十公分，
你不該讓它們在擬合裡說一樣大聲的話。所以要最小化的是**加權**殘差平方和：

```
Σᵢ wᵢ (bᵢ − (Ax)ᵢ)²
```

實作 `weighted_lstsq(A, b, w)`，回傳一個 tuple，四個元素：

```
( x,            ← 長度 n 的解
  residuals,    ← 長度 m，第 i 個是 bᵢ − (Ax)ᵢ（不加權）
  dots,         ← 長度 n，第 j 個是 Σᵢ wᵢ Aᵢⱼ rᵢ
  wrss )        ← Σᵢ wᵢ rᵢ²
```

所有數值回傳 float。

**範例**

```python
A, b = [[0, 1], [1, 1], [2, 1]], [0, 0, 3]

weighted_lstsq(A, b, [1, 1, 1])
# -> ( [1.5, -0.5],                跟 066 的第二個範例一樣
#      [0.5, -1.0, 0.5], [0.0, 0.0], 1.5 )

weighted_lstsq(A, b, [1, 1, 100])
# -> ( [1.7964071856, -0.5988023952],
#      [0.5988023952, -1.1976047904, 0.005988024],
#      [0.0, 0.0], 1.7964071856 )
```

`A`、`b` 一模一樣，只改 `w`，答案就變了——第三點權重 100，直線被拉過去，
殘差從 0.5 掉到 0.006。而 `dots` 兩次都是 0。

## 權重改變了「垂直」的意思

066 的 `dots` 是殘差跟每一行的**普通**內積，是 0。
這題的 `dots` 多了 `wᵢ` 這個因子，而且**還是** 0。這不是湊出來的。

把 `⟨u, v⟩_W = Σᵢ wᵢ uᵢ vᵢ` 當成一個新的內積（`w` 全正才行，不然它不是內積），
那麼加權最小平方就是在**這個**內積下，把 `b` 投影到 `A` 的行空間。
幾何完全沒變，只是「垂直」的定義換了——這就是為什麼 `dots` 非得帶 `wᵢ` 才會是 0。

normal equation 跟著變成

```
(AᵀW A) x = AᵀW b         W = diag(w)
```

n 個未知數、n 條方程式。但 n 可能大於 2，052 那個 2×2 閉式解不夠用了，
你得自己解開這個 n×n 系統。

**限制**
- `1 <= n <= 6`，`n <= m <= 2000`，元素可能是負數或浮點數
- 保證 `w` 全為正，且 `A` 的 n 個行向量線性獨立（`AᵀWA` 可逆）
- **不要用 numpy**
- **不要真的把 W 這個 m×m 矩陣建出來**。`m = 2000` 時那是 400 萬個元素，
  接著老實算 `AᵀW` 要 n·m² 次乘法，大測資的時間上限會擋掉。`wᵢ` 是純量，乘進去就好
- `dots` 和 `wrss` 要真的從你算出的 `residuals` 去算——那才是在驗證 `x` 對不對
- 數值比對容差 `1e-6`
