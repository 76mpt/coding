071 你用冪迭代找出**一個**特徵值。這題要全部——而且要證明你真的找對了。

前提是 `A` 是**實對稱**矩陣。這個條件換來一個很強的結論，叫**譜定理**：

> 任何實對稱矩陣的特徵值全是實數，而且存在一組**互相正交**的特徵向量。
> 也就是存在正交矩陣 `Q`（`QᵀQ = I`）使 `QᵀAQ = Λ` 為對角矩陣。

等價寫法 `A = QΛQᵀ`：把 `A` 讀成「先轉到特徵基底 → 各軸獨立伸縮 → 再轉回來」。
第 11 講講的就是這件事。這題要你**構造**那個 `Q`，不是呼叫 `np.linalg.eigh`。

方法：反覆用「只動兩個座標軸的旋轉」把非對角元素打成 0。
對一組下標 `(p, q)`，取只在這兩個維度上作用的旋轉矩陣 `J`：

```
J[p][p] = J[q][q] = cos θ
J[p][q] = sin θ,  J[q][p] = −sin θ
其餘位置跟單位矩陣一樣
```

然後把 `A` 換成 `JᵀAJ`。**選對 θ 可以讓新矩陣的 `(p, q)` 元素恰好變成 0。**
那個 θ 要你自己推——把 `(JᵀAJ)` 的 `(p,q)` 元素展開、設成 0，是個 2×2 的小計算。

一次旋轉清掉 `(p,q)`，但可能把別處弄回非零。不過「非對角能量」
`Σ_{i≠j} a_ij²` **嚴格下降**：正交變換保住 Frobenius 範數，
被清掉那一格的平方只能跑到對角線上。所以反覆做一定收斂。
每次挑絕對值最大的非對角元素下手，收斂很快。

實作 `spectral_decompose(A)`，回傳三個元素：

```
( eigs,         ← 特徵值，遞減排序
  Q,            ← 第 j 個直行是 eigs[j] 的單位特徵向量，且 QᵀQ = I
  n_positive )  ← 大於 1e-9 的特徵值個數；等於 n 就是正定
```

**範例**

```python
spectral_decompose([[2, 1], [1, 2]])
# -> ( [3, 1], Q, 2 )            Q 的兩個直行是 (1,1)/√2 與 (1,-1)/√2

spectral_decompose([[0, 1], [1, 0]])
# -> ( [1, -1], Q, 1 )            不定矩陣：一正一負

spectral_decompose([[2, 0, 0], [0, 2, 0], [0, 0, 5]])
# -> ( [5, 2, 2], Q, 3 )            已經是對角的，但有重根
```

## 特徵向量不唯一，但這題的答案是唯一的

有重根時特徵向量**根本不唯一**：`diag(2, 2, 5)` 的特徵值 2 對應一整個平面，
那平面上任何一組正交基底都對。符號也一樣——`v` 和 `−v` 都是特徵向量。

所以測資**不比對 `Q` 的具體數值**。它檢查三個性質：

```
QᵀQ = I            特徵向量互相正交、長度 1
A Q = Q Λ          每個直行真的是該特徵值的特徵向量
eigs 跟真值相符     而且遞減排序
```

只要 `Q` 滿足這三條，不管符號怎麼取、重根基底怎麼選都算對，
你推的 θ 用哪個符號慣例也不影響。

這不是放寬標準——**那三條性質就是譜定理的全部內容**。
你在這題要交出來的不是一堆數字，是一個構造性的證明。

**限制**
- `1 <= n <= 8`
- 保證 `A` 實對稱（`A[i][j] == A[j][i]`），元素是整數或浮點數
- 可能有**重根、零特徵值、負特徵值**
- **不要用 numpy**
- `eigs` 遞減排序，`Q` 的直行順序要跟 `eigs` 對應
- 容差 `1e-8`
