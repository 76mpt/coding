030 你算過投影：把 `v` 投影到 `u` 上，剩下的殘差跟 `u` 垂直。
052 你換基底的時候得算 `B⁻¹`，還要除行列式。
這題把這兩件事接起來：**把任意一組基底，改造成兩兩垂直、長度都是 1 的基底**。

方法叫 **Gram-Schmidt**，一句話說完：
**一個一個處理，每個新向量先扣掉它在「已經做好的那些方向」上的投影，剩下的部分縮放成長度 1。**

```
q₁ = v₁ / |v₁|
w₂ = v₂ − (q₁·v₂) q₁                    q₂ = w₂ / |w₂|
w₃ = v₃ − (q₁·v₃) q₁ − (q₂·v₃) q₂       q₃ = w₃ / |w₃|
…
```

每一步扣掉的就是 030 那個投影。因為 `qᵢ` 長度都是 1，投影係數就是內積本身，不用再除 `|qᵢ|²`。

實作 `gram_schmidt(vectors)`，回傳一個 tuple，三個元素：

```
( Q,          ← 正交單位向量 q₁, q₂, …，照上面的順序算
  G,          ← k×k 矩陣，G[i][j] = qᵢ · qⱼ
  rebuilt )   ← 每個原向量 vⱼ 用 Σᵢ (qᵢ·vⱼ) qᵢ 組回來
```

向量都用 list 表示，所有數值回傳 float。

**範例**

```python
gram_schmidt([[3, 4], [1, 0]])
# -> ( [[0.6, 0.8], [0.8, -0.6]],
#      [[1.0, 0.0], [0.0, 1.0]],
#      [[3.0, 4.0], [1.0, 0.0]] )
```

`q₁ = (3, 4) / 5`。`v₂ = (1, 0)` 在 `q₁` 上的投影係數是 `0.6`，
扣掉之後剩 `(0.64, −0.48)`，長度 `0.8`，縮放成 `(0.8, −0.6)`。

## 這題真正要你看到的東西

`G` 是**單位矩陣**，`rebuilt` 就是**原本的向量**。這兩件事合起來說的是：

- `G = I`：q 們兩兩垂直、長度都是 1
- `rebuilt = vectors`：q 們張成的空間跟原本那組一模一樣，**什麼都沒丟**

把 q 們當成行排成矩陣 Q，`G = I` 寫成 `QᵀQ = I`。
這正是 052 一直想要的東西：**這種基底的反矩陣就是轉置**，不用除行列式，也不會數值不穩。

**限制**
- `1 <= k <= n <= 5`，k 是向量個數、n 是維度，元素是整數
- 保證線性獨立，而且離相依很遠（不用處理 `|w| = 0`）
- **不要用 numpy**
- 順序有差：先處理 `[1, 0]` 還是先處理 `[1, 1]`，得到的 Q 不一樣。照輸入順序
- `G` 和 `rebuilt` 要**真的用你算出來的 Q 去算**。直接寫死單位矩陣和原向量，測資一樣會過——
  但那樣你什麼都沒驗證，這題就白做了
