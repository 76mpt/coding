067 你學會了在只能往前的鏈上找路，但全程沒有改動任何一個 `next`。這題開始動手改接線。

反轉是鏈結串列的核心動作，也是最容易把節點弄丟的地方。
list 的反轉是 `vals[::-1]`，一行就結束；鏈的反轉沒有捷徑——
你得一個一個把箭頭轉過來，而且**每轉一個就會失去通往下一個的路**，除非你先把它記下來。

追蹤器收到一段倒著傳來的軌跡（感測器的緩衝區是後進先出），
需要把鏈上第 `left` 到第 `right` 個節點原地翻過來，其他節點保持不動。

實作 `reverse_between(head, left, right)`，回傳整條鏈的新開頭。位置從 **1** 開始算。

**範例**

```python
reverse_between(1 -> 2 -> 3 -> 4 -> 5, 2, 4)   ->   1 -> 4 -> 3 -> 2 -> 5
reverse_between(1 -> 2 -> 3 -> 4 -> 5, 1, 5)   ->   5 -> 4 -> 3 -> 2 -> 1
reverse_between(1 -> 2 -> 3 -> 4 -> 5, 1, 3)   ->   3 -> 2 -> 1 -> 4 -> 5
reverse_between(1 -> 2 -> 3 -> 4 -> 5, 3, 3)   ->   1 -> 2 -> 3 -> 4 -> 5
```

第二、三個例子要特別注意：`left = 1` 的時候整條鏈的開頭會換人，
所以**最後回傳 `head` 是錯的**——你拿在手上的那個 `head` 已經被搬到後面去了。
第四個例子是 `left == right`，反轉一個節點等於什麼都沒做，但你的程式不該在這裡出錯。

**原地**的意思是：只改 `next` 指標。不要新建節點，也不要改任何節點的 `val`——
這題是搬節點，不是搬值。有一筆測資會檢查回傳的鏈是不是由原本那些節點組成的，
用 `ListNode(node.val, ...)` 複製一份新的會被抓到。

## 讓特例消失

這題真正麻煩的地方在 `left = 1`：段的前面沒有節點，
所以「把段前一個的 `next` 接到新的段頭」這個動作無處可做，你得為它單獨寫一條分支。
寫得出來，但分支一多就容易漏掉其中一條。

有一個標準手法能讓這個特例整個消失：**在 `head` 前面掛一個不屬於原始資料的假節點**，
讓「段前一個」永遠存在，最壞情況就是那個假節點自己。
想到它之後，你的程式會從兩種情況縮回一種——而且回傳值也跟著變得很自然。

**限制**
- `0 <= n <= 2 * 10^5`，節點值是整數
- 保證 `1 <= left <= right <= n`；`n = 0` 時 `left = right = 0`，直接回傳 `None`
- 必須就地改接指標，額外空間 **O(1)**
- 大測資有 20 萬個節點並有時間上限。**遞迴寫法會爆 `RecursionError`**，這題要用迭代
