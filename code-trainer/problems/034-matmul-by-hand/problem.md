矩陣乘法的定義是：

```
(AB)ᵢⱼ = Σₖ Aᵢₖ Bₖⱼ
```

「**結果的第 i 列第 j 行**，等於 **A 的第 i 列**和 **B 的第 j 行**的**內積**」——
你上一節（M00.2）寫的那個內積，在這裡被用了 `m × p` 次。

實作 `matmul(A, B)`，用三層迴圈（或 comprehension）算矩陣乘積，**不要用 numpy**。

**維度規則**

```
A 是 m × n      B 是 n × p      AB 是 m × p
        └────────┘
        中間這兩個必須相等，否則乘不起來
```

**範例**

```python
matmul([[1, 2], [3, 4]], [[5, 6], [7, 8]])   ->  [[19, 22], [43, 50]]
```

驗算左上角：`A` 第 0 列 `[1, 2]` 和 `B` 第 0 行 `[5, 7]` 的內積 = `1×5 + 2×7 = 19` ✓

```python
matmul([[1, 2, 3]], [[1], [2], [3]])   ->  [[14]]        # 1×3 乘 3×1 = 1×1
matmul([[1, 0], [0, 1]], [[9, 8], [7, 6]])   ->  [[9, 8], [7, 6]]   # 單位矩陣
```

**矩陣乘法不可交換**

```python
matmul([[1, 2], [3, 4]], [[5, 6], [7, 8]])   ->  [[19, 22], [43, 50]]
matmul([[5, 6], [7, 8]], [[1, 2], [3, 4]])   ->  [[23, 34], [31, 46]]
```

**`AB ≠ BA`。** 這不是特例，是常態——矩陣代表「變換」，先旋轉再縮放跟先縮放再旋轉本來就不同。

**錯誤處理**

- `A` 的行數 ≠ `B` 的列數 → `raise ValueError`

**限制**
- 元素是 int 或 float，矩陣用「list 的 list」表示，每一列長度相同。
- 保證至少 1 列 1 行（不會有空矩陣）。
- 最大約 60×60。
- 回傳的每一列是 list。
