# 034-matmul-by-hand · 手寫矩陣乘法 — 參考解

## 標準解

```python
def matmul(A, B):
    if len(A[0]) != len(B):
        raise ValueError("A 的行數必須等於 B 的列數")
    n = len(B)
    return [[sum(A[i][k] * B[k][j] for k in range(n))
             for j in range(len(B[0]))]
            for i in range(len(A))]
```

三層對應定義的三個部分：

```
(AB)ᵢⱼ = Σₖ Aᵢₖ Bₖⱼ
  ↑  ↑     ↑
  i  j     k
外層 中層  內層（sum 把它加掉）
```

**k 是「被加掉」的那個索引**——它在 A 裡是行號、在 B 裡是列號，兩邊必須等長，這就是維度相容規則的來源。

## 為什麼 (AB)ᵢⱼ 是「A 的第 i 列 · B 的第 j 行」

把 `Σₖ Aᵢₖ Bₖⱼ` 攤開：

```
A 的第 i 列：  (Aᵢ₀, Aᵢ₁, ..., Aᵢₙ₋₁)
B 的第 j 行：  (B₀ⱼ, B₁ⱼ, ..., Bₙ₋₁ⱼ)
逐項相乘再相加 = 內積
```

**矩陣乘法就是「一大堆內積」**——m×p 個。你在 M00.2 寫的 `dot_and_angle` 裡那個 `sum(x*y for x,y in zip(a,b))`，在這裡被呼叫了 m×p 次。

拿 B 的第 j 行要**縱向取**（`B[k][j]`，k 在變），這是最容易寫錯索引的地方。

## AB ≠ BA

測資裡有兩對專門示範：

```
[[1,2],[3,4]] × [[5,6],[7,8]] = [[19,22],[43,50]]
[[5,6],[7,8]] × [[1,2],[3,4]] = [[23,34],[31,46]]

[[1,2,3]] × [[1],[2],[3]] = [[14]]          1×3 · 3×1 → 1×1
[[1],[2],[3]] × [[1,2,3]] = 3×3 的矩陣       3×1 · 1×3 → 3×3
```

後面那對更極端——**連維度都不一樣**。第一個叫內積（inner product），第二個叫外積（outer product），同樣兩個向量，換個順序得到純量或矩陣。

**幾何解釋**：矩陣代表變換。`AB` 讀作「**先做 B，再做 A**」（因為作用在向量上是 `A(Bx)`）。先旋轉再縮放 ≠ 先縮放再旋轉，所以不可交換是常態，可交換才是特例。

> 注意這個「右邊先作用」的慣例——它跟你在 024 寫的 `chain_derivative` 是同一回事：`layers[0]` 是最外層、最後才作用。**函數合成和矩陣乘法共用同一個順序約定。**

## 複雜度

時間 **O(m·n·p)**，方陣就是 **O(n³)**。空間 O(m·p)（結果本身）。

40×40 那筆測資是 64,000 次乘加。純 Python 大約幾十毫秒；`numpy` 的 `A @ B` 會快 100 倍以上，因為它跑在 BLAS（高度優化的 C/Fortran 函式庫），還會用上 CPU 的 SIMD 指令和快取分塊。

**但你現在該手寫一次。** 知道那三層迴圈長什麼樣，你才會在看到 shape 錯誤時立刻反應「哦，中間那個維度沒對上」——那是 S5 和 PyTorch 除錯最常見的錯誤類型（`5.11 shape 除錯` 整節在講這個）。

理論上有更快的演算法（Strassen 的 O(n^2.807)），但常數大、數值穩定性差，實務上只在極大矩陣才划算。

## 常見錯誤

1. **維度檢查寫成 `len(A) != len(B)`** —— 要比的是「A 的**行**數」和「B 的**列**數」，也就是 `len(A[0])` 和 `len(B)`。這兩個很容易搞反。
2. **內層迴圈的索引寫成 `B[j][k]`** —— 那是取 B 的第 j 列，不是第 j 行。結果會變成 `A × Bᵀ`。測資第一筆就會抓到。
3. **結果矩陣的維度用錯** —— 結果是 `len(A) × len(B[0])`，不是 `len(A) × len(A[0])`。非方陣的測資（`1×3 · 3×1`）專門抓這個。
4. **假設是方陣** —— 用 `range(n)` 跑所有三層。方陣測資會過，非方陣立刻爆 IndexError。
5. **回傳 tuple 的 tuple** —— 題目要 list 的 list。
6. **用 numpy** —— 這題的重點就是手寫。之後 5.1 會讓你改用 numpy，但要先知道它在做什麼。

## 延伸

矩陣乘法是線性代數的核心運算，之後幾乎每一節都會用到：

| 節點 | 用矩陣乘法做什麼 |
|---|---|
| **M0.1** 線性映射 | 矩陣乘向量 = 把向量送進一個線性變換 |
| **M0.5** SVD | `A = UΣVᵀ`，三個矩陣連乘 |
| **M0.8** 反向傳播 | 每一層的梯度是 Jacobian 連乘——**矩陣乘法不可交換，所以順序不能錯** |
| **M2.2** 相機模型 | 投影矩陣 `P = K[R|t]`，內參乘外參 |
| **5.5** 手寫卷積 | **im2col** 把卷積變成一次大矩陣乘法，這是所有深度學習框架的實作方式 |

下一題會讓你算 2×2 的行列式，並驗證 `|det|` 就是「單位正方形被這個矩陣變換後的面積」——那是理解「矩陣在做什麼」的第二把鑰匙。
