上一題你寫了旋轉矩陣。這題驗證它最重要的性質，並且看到**複數其實在做同一件事**。

## 旋轉矩陣（複習自 044）

```
        ⎡ cos θ   −sin θ ⎤
R(θ) =  ⎢                 ⎥
        ⎣ sin θ    cos θ ⎦
```

也就是 `[[cos θ, -sin θ], [sin θ, cos θ]]`。

starter 裡的 `rotation_matrix(theta)` 就是要回傳這個 2x2 矩陣——
它不是這題的入口，是給你自己用的工具函式，`compose_rotations` 裡會用到三次。

## 要驗證的性質

**先轉 α 再轉 β，等於直接轉 α+β：**

```
R(α) · R(β) = R(α + β)
```

這件事一點都不顯然——左邊是**矩陣乘法**（八次乘法四次加法），右邊只是**角度相加**。
它們相等，是因為**和角公式**：

```
cos(α+β) = cos α cos β − sin α sin β
sin(α+β) = sin α cos β + cos α sin β
```

**那兩條公式就是矩陣乘法展開後的結果。** 你等一下會親眼看到。

## 要實作的函式

```python
compose_rotations(alpha, beta)
```

回傳一個 tuple，四個元素：

```
( R(α)·R(β) 這個 2x2 矩陣,      ← 用矩陣乘法算，不要偷懶直接算 R(α+β)
  R(α+β) 這個 2x2 矩陣,
  e^{iα} · e^{iβ} 這個複數,      ← 用 Python 的複數型別
  e^{i(α+β)} 這個複數 )
```

矩陣用「list 的 list」表示：`[[a, b], [c, d]]`。

**複數的部分**

歐拉公式：

```
e^{iθ} = cos θ + i sin θ
```

Python 的複數寫成 `complex(實部, 虛部)`，或用字面值 `3+4j`。
所以 `e^{iθ}` 就是 `complex(math.cos(theta), math.sin(theta))`。

**兩個複數相乘，效果就是角度相加**——這跟旋轉矩陣相乘是同一件事，只是換了個表示法。

**範例**

```python
m1, m2, c1, c2 = compose_rotations(0.3, 0.7)

m1  ->  [[0.5403023059, -0.8414709848], [0.8414709848, 0.5403023059]]
m2  ->  [[0.5403023059, -0.8414709848], [0.8414709848, 0.5403023059]]    # 一模一樣
c1  ->  (0.5403023059+0.8414709848j)
c2  ->  (0.5403023059+0.8414709848j)                                     # 一模一樣
```

`0.3 + 0.7 = 1.0`，而 `cos(1) = 0.5403`、`sin(1) = 0.8415`——四個結果全部對上。

**注意複數的實部虛部**，剛好就是矩陣的第一行：`(cos, sin)`。
**那不是巧合**，參考解會說明。

**限制**
- `alpha`、`beta` 是弧度，可以是負的。
- 矩陣用 `[[a,b],[c,d]]`，元素是 float。
- 判定使用近似比較，容差 10⁻⁹。
- **`m1` 必須真的用矩陣乘法算出來**（隱藏測資會用不同的角度組合檢查）。
