上一題的等比級數 `Σ rᵏ` 在 `|r| < 1` 時收斂。
**這題的調和級數每一項也趨近 0，但它發散。**

```
H_n = 1 + 1/2 + 1/3 + … + 1/n        →  ∞
```

「每項都趨近 0」**不保證級數收斂**——這是分析學最重要的反例。

它發散得非常慢：`H_n ≈ ln(n) + γ`，其中 `γ ≈ 0.5772156649` 是**歐拉–馬斯凱羅尼常數**。
加到 100 萬項也才 14.4。

## 要實作的函式

```python
series_facts(n)
```

回傳三個東西：

```
( H_n,                      ← 調和級數前 n 項，逐項累加
  H_n − (ln(n) + γ),        ← 跟漸近式的誤差（n >= 1 時；n = 0 回傳 None）
  砍半次數 )                 ← n 一直整數除以 2，砍幾次會剩 1
```

`γ = 0.5772156649015329`（直接寫在程式裡）。

**「砍半次數」的定義**

```python
count = 0
while n > 1:
    n //= 2
    count += 1
```

那個 `count` 就是 `floor(log₂ n)`——**二分搜尋要走幾步**。

**範例**

```python
series_facts(1)        ->  (1.0, 0.4227843350984671, 0)
series_facts(10)       ->  (2.9289682539682538, 0.04916749607267513, 3)
series_facts(1000)     ->  (7.485470860550343, 0.0004999166680... , 9)
series_facts(0)        ->  (0.0, None, 0)
```

**注意第二項怎麼變化**：`n=1` 時誤差 0.42，`n=10` 時 0.049，`n=1000` 時 0.0005——
**每放大 100 倍，誤差縮小 100 倍**。誤差大約是 `1/(2n)`，所以 `ln(n) + γ` 是非常好的近似。

**注意第三項**：`n=10` 的砍半次數是 **3**（10→5→2→1），不是 4。
`floor(log₂ 10) = 3`。

## 為什麼調和級數會發散

把項數分組，每組的和都 ≥ 1/2：

```
1
+ 1/2
+ (1/3 + 1/4)          > 1/4 + 1/4 = 1/2
+ (1/5 + … + 1/8)      > 4 × 1/8  = 1/2
+ (1/9 + … + 1/16)     > 8 × 1/16 = 1/2
…
```

**每組貢獻至少 1/2，而組數可以無限多**，所以總和無上界。

組數是 `log₂ n`，每組貢獻 ≥ 1/2——**這就是 `H_n` 大約等於 `ln n` 的直觀來源**。

**限制**
- `n >= 0`，最多 10⁵。
- 判定使用近似比較，容差 10⁻⁹。
- `n = 0` 時第一項是 0.0、第二項是 None、第三項是 0。
