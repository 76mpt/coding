# 030-project-and-residual · 投影與殘差正交 — 參考解

## 標準解

```python
def project(a: list[float], b: list[float]) -> tuple[list[float], list[float]]:
    if len(a) != len(b):
        raise ValueError("兩個向量的維度必須相同")

    ab = sum(x * y for x, y in zip(a, b))     # a·b
    bb = sum(y * y for y in b)                # b·b = |b|²

    if bb == 0:
        raise ValueError("b 是零向量，沒有方向可以投影")

    s = ab / bb                               # 係數：沿著 b 走幾倍
    p = [s * y for y in b]                    # 投影向量
    r = [x - y for x, y in zip(a, p)]         # 殘差
    return p, r
```

七行，沒有迴圈變數需要維護，三個 comprehension 各做一件事。

## 公式怎麼推出來的

不要背，推一次就永遠記得。**把「投影」寫成一個條件**：

我們要找一個沿著 `b` 的向量 `p = s·b`（`s` 是待定的倍數），使得剩下的 `r = a − p` **與 b 正交**：

```
r · b = 0
(a − s·b) · b = 0
a·b − s (b·b) = 0
       s = (a·b) / (b·b)
```

**`s` 不是猜的，是「殘差要正交」這個要求逼出來的唯一解。**
這也是為什麼驗證正交性能證明你算對了——那個條件就是投影的定義本身。

### 分母為什麼是 `b·b` 不是 `|b|`

最常見的記錯。拆開看：

```
p = (a·b / |b|) × (b / |b|)
     └─ a 在 b 方向上的「長度」┘  └─ b 的單位向量 ┘
```

**兩個 |b| 各有各的職責**：第一個把 `a·b` 中屬於 b 長度的部分除掉、留下純量長度；第二個把 b 正規化成單位長度、只留方向。合起來就是 `|b|² = b·b`。

寫成 `b·b` 還有個好處：**不用開根號**，少一次捨入、也少一次浮點運算。

### 特例檢查

- `a·b = 0`（a 與 b 已正交）→ `s = 0` → `p` 是零向量、`r = a`。測資 `[1,2,2]` 與 `[2,-1,0]` 就是這種。
- `a` 沿著 b（`a = k·b`）→ `s = k` → `p = a`、`r` 是零向量。測資 `[2,2]` 與 `[1,1]`。
- **`b` 的長度不影響結果**——`project(a, [1,0])` 和 `project(a, [7,0])` 給完全一樣的答案，因為 `s` 的分母會把長度吃掉。投影只在乎 b 的**方向**。

## 為什麼「驗證正交」比「比對答案」更有價值

這是整個數學軌的方法論。比對答案只能告訴你「這一筆對了」；驗證性質是**用一個獨立的數學事實**去檢查實作：

```python
sum(x * y for x, y in zip(r, b))    # 應該是 1e-16 這種量級
```

如果你把 `s` 的分母寫成 `|b|` 而不是 `b·b`，答案會錯，而**正交性檢查會立刻抓到**（算出來不是 0）——即使你手邊沒有正確答案可以對照。

這種「用性質驗證實作」的手法之後會一直用：
- **M0.2**：手寫 Gram-Schmidt，檢查產出的基兩兩正交
- **M0.3**：最小平方，檢查殘差與每個基向量正交
- **M2.8**：李群 exp/log，檢查 `log(exp(x)) == x` 往返一致
- **S5.9**：手寫 autograd，用有限差分檢查解析梯度（你在 023 做過）

## 複雜度

時間 **O(n)**（三趟：兩個內積、一次乘、一次減，都是線性），空間 **O(n)**（要回傳兩個 n 維向量，這是必要的）。

用 numpy 的話是 `s = a @ b / (b @ b); p = s * b; r = a - p`，同樣 O(n) 但常數小很多（向量化在 C 層跑）。**S5.1 NumPy 向量化整節就在練把這種逐分量的 comprehension 換成陣列運算。**

## 常見錯誤

1. **分母寫成 `|b|` 或 `sqrt(b·b)`** —— 最常見。結果會差一個 |b| 倍。用 `[1,2]` 與 `[3,4]` 測：正確是 `[1.32, 1.76]`，錯的會是 `[3.96, 5.28]`。正交性檢查會立刻抓到。
2. **零向量 b 沒擋** —— `bb = 0` 導致 `ZeroDivisionError`（或 float 的 `nan`），而規格要的是 `ValueError`。
3. **把 a 是零向量也擋掉** —— 那是合法輸入，投影和殘差都是零向量。測資 `[0,0]` 與 `[1,1]` 專門抓這個。**多擋比少擋更難發現**，因為它看起來很「防禦性」。
4. **`r` 用 `a − s·b` 重算而不是 `a − p`** —— 數學上等價，但多做一次乘法、多一次捨入。既然 `p` 已經算好了，直接用。
5. **回傳 tuple 的順序反了** —— 題目要 `(投影, 殘差)`。兩者長度相同、看起來都像向量，反了不會報錯，只會安靜地錯。
6. **`bb == 0` 改用容差判斷** —— 這裡不該近似。只有真正的零向量才會讓 `Σy²` 得到剛好 0.0；用 `< 1e-12` 會把「非常短但合法」的 b 誤判掉。

## 延伸：投影在 CV 與 SLAM 的哪裡

這七行是後面一大票東西的原子操作：

| 節點 | 用投影做什麼 |
|---|---|
| **M0.2 Gram-Schmidt** | 反覆「減去在已有基向量上的投影」，把一組向量正交化 |
| **M0.3 最小平方** | 解 `Ax ≈ b` 就是把 b 投影到 A 的行空間上，殘差正交於行空間 |
| **M0.5 SVD** | 低秩近似 = 投影到前 k 個奇異向量張成的子空間 |
| **M2.5 三角測量** | 重投影誤差：3D 點投影回影像平面，跟觀測到的 2D 點比較 |
| **M4.5 PCA** | 「找一個方向使投影後的變異數最大」，就是這題的公式做 n 次 |

**下一個節點 M00.3（矩陣運算）會告訴你：矩陣乘法的每一格就是一個內積**，而投影其實可以寫成一個矩陣 `P = bbᵀ/(bᵀb)` 乘上 a——那時候你會回頭看這七行，發現它一直是個線性映射。
