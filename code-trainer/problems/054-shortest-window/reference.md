# 054-shortest-window · 最短的達標區間 — 參考解

## 標準解

```python
def shortest_window(counts, target):
    left = 0
    total = 0
    best = float('inf')

    for right, x in enumerate(counts):
        total += x                          # 右界擴張
        while total >= target:              # 達標就盡量縮左界
            best = min(best, right - left + 1)
            total -= counts[left]
            left += 1

    return best if best != float('inf') else 0
```

時間 O(n)，空間 O(1)。

看起來有巢狀迴圈，但**內層的 `while` 總共只會執行 n 次**——
`left` 每次執行加 1，而它最多從 0 走到 n。所以兩個指標各走 n 步，總共 2n 步。
這種「看起來 O(n²) 其實是 O(n)」的分析叫**攤還分析（amortized analysis）**，
是雙指標題最常被面試官追問的地方。

這已經是最佳解——你至少要看過每個元素一次，O(n) 是下界。

## 為什麼右界不用回頭（正確性論證）

這是這題唯一需要證明的事，而且**只有在元素非負時才成立**。

假設右界在 R 時，左界已經縮到 L（再縮就不達標了）。現在右界要移到 R+1。
問：左界有沒有可能需要退回 L 之前？

不可能。因為 `[L-1, R]` 當初是達標的（我們就是從那裡縮過來的），
而 `[L-1, R+1]` 包含它，和只會更大，長度卻更長——不可能是更好的答案。
所以左界只需要繼續往右試，永遠不用回頭。

**非負這個條件是關鍵。** 如果允許負數，「往右擴和只會變大」就不成立了，
這個貪心的伸縮邏輯整個垮掉。有負數的版本要改用**前綴和 + 單調佇列**，
那是完全不同的題（LeetCode 862，難度 hard）。

每次看到滑動視窗，都要先問自己：**這題的單調性是什麼？** 沒有單調性就不能用。

## 另一種寫法：前綴和 + 二分

```python
import bisect

def shortest_window(counts, target):
    prefix = [0]
    for x in counts:
        prefix.append(prefix[-1] + x)
    best = float('inf')
    for right in range(1, len(prefix)):
        need = prefix[right] - target
        i = bisect.bisect_right(prefix, need) - 1
        if i >= 0:
            best = min(best, right - i)
    return best if best != float('inf') else 0
```

O(n log n)，比滑動視窗慢一個 log。但它靠的是**前綴和遞增**（一樣需要非負），
用二分找「最靠右的、夠小的前綴和」。

值得知道這個寫法，因為它推廣性更好——有些變形題滑動視窗做不了，二分還可以。

## 常見錯誤

1. **內層用 `if` 而不是 `while`**——只縮一格就跑掉，拿不到以這個右界結尾的最短區間。
   `[1,1,1,1,1]` 配 target 5 還是會對，但 `[8,1,1,1,8]` 配 9 就錯了。

2. **長度算成 `right - left`**——差一錯誤。少算 1，答案全部小 1。
   單元素的測資 `[5]` 配 5 會回 0 而不是 1，一測就知道。

3. **在收縮之後才記錄長度**——`left` 已經變了，記到的是縮完之後的長度，會偏小。

4. **`best` 初始值設成 0**——那 `min()` 永遠是 0，最後回傳 0。
   要用 `inf` 或 `n+1` 這種「不可能的大值」。

5. **找到第一個達標就回傳**——題目要**最短的**，不是第一個。
   `[3,4,1,1,9]` 配 8：第一個達標的是 `[3,4,1]`（長度 3），但答案是 1（單獨那個 9）。

6. **每次重算區間和**——`sum(counts[left:right+1])` 寫在迴圈裡，
   整體變回 O(n²)，大測資會超時。和要用加減維護。
