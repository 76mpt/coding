# 062-first-bad-bracket · 找出第一個壞掉的括號

- 階段：資料結構與演算法（LeetCode 風格） / 2.3 堆疊與佇列
- 語言：Python　難度：warmup　互動方式：實作函式
- 要實作的入口：`first_bad_bracket`
- 提示：共 4 階（`python trainer.py hint 062-first-bad-bracket`）
- 測資：14 筆（`python trainer.py test 062-first-bad-bracket`）

────────────────────────────────────────────────────────────────────

你在寫一個標註檔的語法檢查器。檔案裡有三種括號 `()`、`[]`、`{}`，
巢狀沒關係，但必須正確配對。壞掉的時候，光說「格式錯誤」沒有用——
要指出**是哪一個字元出問題**，使用者才知道去哪裡修。

實作 `first_bad_bracket(s)`，回傳第一個出問題的字元索引；整份都正確就回傳 `-1`。

「出問題」有兩種：

- **多餘或錯配的右括號**：掃到一個右括號，但它配不上最近一個還沒配對的左括號
  （或是根本沒有左括號在等）→ 回傳**這個右括號的索引**
- **沒被關起來的左括號**：整份掃完還有左括號沒配對 → 回傳**其中最靠左的那一個的索引**

右括號的問題**優先**：如果兩種都有，先回傳掃描時最早遇到的那個壞右括號。
括號以外的字元（英文、數字、空白、標點）一律略過。

**範例**

```python
first_bad_bracket("{bbox: [1, 2], id: (7)}")   ->  -1     # 完全正確
first_bad_bracket("([)]")                      ->  2      # ) 想配 (，但最近沒配對的是 [
first_bad_bracket("(()")                       ->  0      # 索引 1-2 配成一對，索引 0 沒關起來
first_bad_bracket("())")                       ->  2      # 第二個 ) 沒有左括號在等
first_bad_bracket("")                          ->  -1
```

第三個例子值得多看一眼：沒關起來的是索引 0，不是索引 2。
**要回傳的是最靠左的那個孤兒左括號**，不是最後一個。

**限制**
- `0 <= len(s) <= 2 * 10^5`
- 括號只有 `()`、`[]`、`{}` 三種，其他字元略過
- 回傳 `int`

**效能要求**：大測資有 200,000 個字元與時間上限。
「反覆掃描字串、每次把配好的一對刪掉」是 O(n²)，會超時。

這題要你看出一件事：掃到一個右括號的時候，你需要知道的是
**最近一個還沒被配對的左括號是誰**。哪種資料結構能 O(1) 回答這個問題？
