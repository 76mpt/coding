# 066-fit-line-least-squares · 用最小平方擬合一條直線

- 階段：數學基礎（Tier 0：沒有就寸步難行） / M0.3 投影與最小平方

- 要實作的入口：`fit_line`

────────────────────────────────────────────────────────────────────

上一題你把向量投影到子空間，殘差垂直於子空間。這題是同一件事換一個問法：
**用一條直線去擬合一堆量測點。**

你有 m 個量測 `(xᵢ, yᵢ)`，想找 `y = a x + b` 讓它最貼近。
只要 m > 2，通常**沒有**一條直線能穿過所有點——這叫**過定方程組**（方程式比未知數多）：

```
a x₁ + b = y₁
a x₂ + b = y₂        ← 未知數只有 a、b 兩個，方程式卻有 m 條
…
```

解不出來，那就退一步：找讓**殘差平方和 `Σ (yᵢ − a xᵢ − b)²` 最小**的 `a, b`。
這個條件等價於**殘差向量垂直於兩個「行」**——一個是 x 的那一行，一個是全 1 的那一行。
把垂直條件寫開就是兩條方程式（**normal equation**）：

```
a Σxᵢ² + b Σxᵢ = Σxᵢyᵢ
a Σxᵢ  + b m   = Σyᵢ
```

兩個未知數兩條方程式，用 2×2 的閉式解（052 那個反矩陣公式）就解得出來。

實作 `fit_line(xs, ys)`，回傳一個 tuple，四個元素：

```
( [a, b],       ← 斜率與截距
  residuals,    ← 每個點的 yᵢ − (a xᵢ + b)
  dots,         ← [殘差·x 那一行, 殘差·全 1 那一行]
  sse )         ← 殘差平方和
```

所有數值回傳 float。

**範例**

```python
fit_line([0, 1, 2], [1, 3, 5])
# -> ( [2.0, 1.0],            剛好穿過三點：y = 2x + 1
#      [0.0, 0.0, 0.0],       殘差全是 0
#      [0.0, 0.0],
#      0.0 )

fit_line([0, 1, 2], [0, 0, 3])
# -> ( [1.5, -0.5],
#      [0.5, -1.0, 0.5],      擬合不完美，殘差不為 0
#      [0.0, 0.0],            但殘差仍然垂直於兩個行
#      1.5 )
```

## 這題真正要你看到的東西

第二個範例裡殘差**不是** 0，`dots` 卻還是 0。這不是巧合，是最小平方的**定義**：

> 殘差平方和最小 ⟺ 殘差垂直於「所有可能的擬合值」張成的子空間

那個子空間就是 x 那一行和全 1 那一行張成的平面。
所以你剛做的事跟上一題完全一樣——**把 y 投影到那個平面上**，`a x + b` 是投影，殘差是垂直的部分。

normal equation 只是把「垂直」兩個字寫成聯立方程式而已。

**限制**
- `2 <= m <= 10^4`，`xs` 與 `ys` 等長，元素可能是負數或浮點數
- **保證 `xs` 至少有兩個不同的值**（否則直線的斜率無意義，方程組無唯一解）
- **不要用 numpy**
- `dots` 和 `sse` 要真的從你算出的殘差去算——那才是在驗證 `a, b` 對不對
