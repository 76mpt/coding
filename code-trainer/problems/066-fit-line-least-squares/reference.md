# 066-fit-line-least-squares · 用最小平方擬合一條直線 — 參考解

## 標準解

```python
def fit_line(xs, ys):
    m = len(xs)
    Sx = sum(xs)
    Sy = sum(ys)
    Sxx = sum(x * x for x in xs)
    Sxy = sum(x * y for x, y in zip(xs, ys))

    D = m * Sxx - Sx * Sx                        # 行列式，題目保證 != 0
    a = (m * Sxy - Sx * Sy) / D
    b = (Sxx * Sy - Sx * Sxy) / D

    residuals = [y - (a * x + b) for x, y in zip(xs, ys)]
    dots = [sum(r * x for r, x in zip(residuals, xs)), sum(residuals)]
    sse = sum(r * r for r in residuals)
    return [a, b], residuals, dots, sse
```

時間 O(m)——**只掃一遍**就能算完五個和。空間 O(m)（輸出殘差）。

## 推導：從「平方和最小」到 normal equation

定義 `f(a, b) = Σ (yᵢ − a xᵢ − b)²`。它對 a、b 都是開口向上的二次函數，
所以極小值在偏導數為 0 的地方：

```
∂f/∂a = Σ 2(yᵢ − a xᵢ − b)(−xᵢ) = 0    →    Σ rᵢ xᵢ = 0
∂f/∂b = Σ 2(yᵢ − a xᵢ − b)(−1)  = 0    →    Σ rᵢ    = 0
```

**這兩條式子就是 `dots = [0, 0]`。** 偏導數為 0 的條件，直接長成「殘差垂直於兩個行」。

展開就是 normal equation：

```
Σ rᵢ xᵢ = 0  →  Σ(yᵢ − a xᵢ − b) xᵢ = 0  →  a Sxx + b Sx = Sxy
Σ rᵢ    = 0  →  Σ(yᵢ − a xᵢ − b)    = 0  →  a Sx  + b m  = Sy
```

用矩陣寫，把 x 那一行和全 1 那一行排成 `A`（m×2），未知數 `c = [a, b]`：

```
Aᵀ(y − A c) = 0     →     AᵀA c = Aᵀ y
```

**`AᵀA c = Aᵀ y` 就是 normal equation 的一般形式**，`AᵀA` 正是那個 2×2 矩陣 `[[Sxx, Sx], [Sx, m]]`。

## 跟上一題是同一件事

`A c` 是所有可能的擬合值，它們構成 `A` 的**行空間**——一個二維子空間（住在 m 維空間裡）。
最小平方在做的事是：**在那個子空間裡找離 `y` 最近的點**。

上一題證過「最近 ⟺ 殘差垂直」。所以：

| 上一題 | 這一題 |
|---|---|
| 投影 `p` | 擬合值 `a x + b` |
| 殘差垂直於基底 | `dots = [0, 0]` |
| 子空間 = basis 張成 | 子空間 = x 行與全 1 行張成 |
| `P = A(AᵀA)⁻¹Aᵀ` | 解 `AᵀA c = Aᵀy` |

**最小平方不是「另一個技巧」，它就是投影。**

## 另一個觀點：a 是共變異數除以變異數

把 `a` 的分子分母同除 `m²`：

```
a = (Sxy/m − (Sx/m)(Sy/m)) / (Sxx/m − (Sx/m)²) = Cov(x, y) / Var(x)
```

048 那題你算過 `Var(X) = E[X²] − (E[X])²`，這裡分母就是它。
統計課本的迴歸係數公式跟線代課本的 normal equation 是同一個東西的兩種寫法。

而 `Σrᵢ = 0` 的幾何意義是：**擬合線一定穿過資料重心 `(x̄, ȳ)`**。
把 `x = x̄` 代進 `y = ax + b` 驗證一下就知道。

## 數值警告：別在大問題上用這個公式

這題的閉式解在 m ≤ 10⁴、資料規模正常時完全沒問題。但它有兩個弱點：

1. **`AᵀA` 的條件數是 `A` 的平方**（M0.6 會量化）。x 的值很大或很集中時，
   `D = m·Sxx − Sx²` 是兩個巨大且接近的數相減——**災難性抵消**，就是 048 那題的老問題。
   例如 `xs = [1e8, 1e8+1, 1e8+2]`，D 的有效位數會被吃光。
   實務上的對策是**先中心化**（減掉平均值）再擬合，最後把截距換算回來。
2. **推廣到 k 個未知數要解 k×k 系統**，直接求反矩陣既慢又不穩。

`np.linalg.lstsq` 用的是 QR 或 SVD，不碰 `AᵀA`。這題手寫 normal equation 的目的是
**看清楚它從哪裡來**，不是主張它是最好的實作。

## 常見錯誤

1. **a 和 b 的公式互換**——最常見。`[0,1,2] → [1,3,5]` 應該是 `a=2, b=1`，
   換過來會得到 `a=1, b=2`，殘差立刻不為 0。

2. **行列式寫成 `Sxx * m - Sx` 或忘了平方**——量綱就不對了，隨便一組資料都會錯。

3. **`dots` 的第一個元素用 `Σrᵢ` 第二個用 `Σrᵢxᵢ`**——順序反了。
   題目說第一個是跟 x 那一行的內積。

4. **殘差算成 `(a x + b) − y`**——差一個負號。`sse` 和 `dots` 剛好都不受影響
   （平方、以及 0 取負還是 0），但 `residuals` 本身全部反號，測資會抓到。

5. **整數除法**——在 Python 3 裡 `/` 已經是浮點除法，但如果你手滑寫 `//` 就全錯了。

## 延伸

- **加權最小平方**：每個量測的可信度不同時，把平方和改成 `Σ wᵢ rᵢ²`，
  normal equation 變成 `AᵀWA c = AᵀW y`。SLAM 裡 W 是量測的資訊矩陣（雜訊共變異數的反矩陣），
  這就是為什麼那邊的目標函數長成 `Σ rᵢᵀ Σ⁻¹ rᵢ`。
- **非線性最小平方**：殘差對參數不是線性的時候（例如擬合圓、估計相機姿態），
  就在當前點做線性化、解一次 normal equation、往前走一步、再線性化——
  那是 **Gauss-Newton**，M1.4 的內容，也是 bundle adjustment 的核心迴圈。
- **RANSAC**：資料有離群值時，最小平方會被一個爛點拖歪（平方讓大殘差的影響更大）。
  對策是隨機取小樣本擬合、數有多少點同意，重複很多次。CV 裡估 homography、
  基礎矩陣都是 RANSAC 包著最小平方。
