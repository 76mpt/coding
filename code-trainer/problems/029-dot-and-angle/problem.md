# 029-dot-and-angle · 內積的兩種算法

內積有**兩個看起來完全不同的定義**：

```
座標式   a·b = Σ aᵢbᵢ = a₁b₁ + a₂b₂ + … + aₙbₙ
幾何式   a·b = |a| |b| cos θ
```

一個是純算術，一個講的是長度與夾角。**它們永遠相等**——這題就是要你親手驗證這件事。

實作 `dot_and_angle(a, b)`，回傳 `(內積, 夾角)`：

1. **內積**用座標式算：`Σ aᵢbᵢ`。
2. **夾角**用幾何式反推，單位是**弧度**，範圍 `[0, π]`：

```
            a·b
θ = arccos ─────────
           |a| |b|
```

其中 `|a| = √(Σ aᵢ²)`。

**範例**

```python
dot_and_angle([1, 0], [0, 1])    ->  (0.0, 1.5707963267948966)   # 垂直，θ = π/2
dot_and_angle([1, 0], [1, 0])    ->  (1.0, 0.0)                  # 同向，θ = 0
dot_and_angle([1, 0], [-1, 0])   ->  (-1.0, 3.141592653589793)   # 反向，θ = π
dot_and_angle([3, 4], [4, 3])    ->  (24.0, 0.283794109208328)
```

**內積的符號告訴你什麼**：正 = 夾角小於 90°（大致同向），零 = 垂直，負 = 大致反向。
這個「用一個數字判斷方向關係」的能力，是它在幾何上真正有用的地方。

## 一定要處理的浮點陷阱

`arccos` 的定義域只有 `[-1, 1]`。而 `(a·b)/(|a||b|)` 在數學上保證落在這個範圍內（柯西–施瓦茲不等式），
**但浮點運算會讓它超出去**：

```python
a = [1.1, 2.2, 3.3]
dot(a, a) / (norm(a) * norm(a))   # 1.0000000000000002  ← 大於 1！
math.acos(1.0000000000000002)     # ValueError: math domain error
```

隨機取一個三維向量跟它自己算，**大約四分之一的機率會踩到**。
所以你必須把 cos 值**夾回 `[-1, 1]`** 再丟給 `arccos`。

**錯誤處理**

- `a` 和 `b` 長度不同 → `raise ValueError`
- 任一個是零向量（長度為 0）→ `raise ValueError`（零向量沒有方向，夾角無定義）

**限制**
- 元素是 int 或 float，最多 10⁵ 維。
- 判定使用近似比較，容差約 10⁻⁹。
- 不需要用 numpy，用內建的就好。
