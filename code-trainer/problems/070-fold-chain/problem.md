# 070-fold-chain · 把軌跡對折重排

- 階段：資料結構與演算法（LeetCode 風格） / 2.4 鏈結串列
- 語言：Python　難度：standard　互動方式：實作函式
- 要實作的入口：`fold_chain`
- 提示：共 4 階（`python trainer.py hint 070-fold-chain`）
- 測資：12 筆（`python trainer.py test 070-fold-chain`）

────────────────────────────────────────────────────────────────────

067 你學會用快慢指標找中點，068 你學會反轉一段。
這題把兩個拼起來，再補上 2.4 最後一項技能：**合併**。

追蹤器要把一段軌跡「對折」比對：第一幀配最後一幀、第二幀配倒數第二幀，
依序串成一條新鏈，這樣一次掃描就能看完頭尾的對應關係。也就是把

```
L0 → L1 → L2 → … → Ln-2 → Ln-1
```

重排成

```
L0 → Ln-1 → L1 → Ln-2 → L2 → …
```

實作 `fold_chain(head)`，回傳重排後的鏈頭。

**範例**

```python
fold_chain(1 -> 2 -> 3 -> 4)        ->   1 -> 4 -> 2 -> 3
fold_chain(1 -> 2 -> 3 -> 4 -> 5)   ->   1 -> 5 -> 2 -> 4 -> 3
fold_chain(1 -> 2 -> 3)             ->   1 -> 3 -> 2
fold_chain(1 -> 2)                  ->   1 -> 2
fold_chain(None)                    ->   None
```

奇數長度要注意：正中間那個節點**落在最後**，它沒有配對的對象。

就地的規定跟 068 一樣（只改 `next`、不新建節點），但這題多一條：
**不要改任何節點的 `val`**。

把所有值收集成 list、重排、再寫回每個節點的 `val`——這個做法會印出正確的順序，
但它搬的是**值**而不是**節點**。實務上節點身上還掛著別的東西
（時間戳、特徵點、影像指標），搬值就全錯位了。有測資會檢查每個節點的 `val` 沒被動過。

## 三個動作，你都已經會了

這題不需要任何新技巧。把目標順序盯著看久一點，
你會發現它就是「前半段」和「**反過來的**後半段」交錯穿插的結果。

前半段怎麼找 → 067。後半段怎麼反過來 → 068。剩下的交錯只是兩個指標輪流接。

真正要小心的是接縫：切在哪裡、奇數長度時正中間那個算前半還是後半、
以及**最後一個節點的 `next` 有沒有收尾成 `None`**。
忘了收尾就會留下一個環，走訪時直接卡死——你在 067 已經見過那個後果。

**限制**
- `0 <= n <= 2 * 10^5`，節點值是整數，可能重複
- 只改 `next`：不新建節點、不改 `val`
- 額外空間 **O(1)**。把節點收集成一個 list 再按順序重接也會過（而且沒改 `val`），
  那是合法做法，但它繞過了這題要練的三個指標動作。測資擋不住它，擋你的是你自己
- 大測資有 20 萬個節點並有時間上限。**深度 O(n) 的遞迴會爆**，同 068
