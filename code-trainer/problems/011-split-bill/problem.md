# 011-split-bill · 分帳與無條件進位

- 階段：基本功：語法與函式 / 1.1 變數、型別、數值運算
- 語言：Python　難度：standard　互動方式：實作函式
- 要實作的入口：`split_bill`
- 提示：共 4 階（`python trainer.py hint 011-split-bill`）
- 測資：8 筆（`python trainer.py test 011-split-bill`）

────────────────────────────────────────────────────────────────────

一群人吃飯要分帳。實作 `split_bill(total, people, tip_percent)`：

1. 先算**含小費的總額**：`total × (1 + tip_percent/100)`，**四捨五入成整數**。
2. 每個人付的錢必須是**整數**，而且**不能少收**——所以要用**無條件進位**。
3. 回傳 `(每人付多少, 總共多收了幾元)`。

「多收的」= 每人付 × 人數 − 含小費總額。

**範例**

```
split_bill(1000, 3, 10)
```

含小費總額 = round(1000 × 1.1) = 1100。
1100 ÷ 3 = 366.67，無條件進位是 **367**。
3 個人共付 367 × 3 = 1101，比 1100 多了 **1**。
所以回傳 `(367, 1)`。

```
split_bill(1000, 4, 0)   ->  (250, 0)     # 剛好整除，沒有多收
split_bill(999, 7, 15)   ->  (165, 6)
split_bill(1, 3, 0)      ->  (1, 2)       # 1 元三個人分，每人還是得付 1 元
```

**限制**
- `total >= 0`，`people >= 1`，`tip_percent >= 0`，都是整數。
- 回傳的兩個值都必須是 `int`，不能是 `float`。

**重點**：Python 的 `//` 是**無條件捨去**（往負無窮方向），不是無條件進位。
這題就是要你想清楚怎麼用整數運算做出「進位」。
