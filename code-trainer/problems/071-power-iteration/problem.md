# 071-power-iteration · 冪迭代找主特徵值

- 階段：數學基礎（Tier 0：沒有就寸步難行） / M0.4 特徵值與特徵向量

- 提示：共 4 階（`python trainer.py hint 071-power-iteration`）

069 收掉了投影那條線。這節換個問題：
**矩陣作用在向量上時，有哪些方向不會被轉開？**

`A v = λ v` 的解 `(λ, v)` 就是特徵值與特徵向量。`v` 的方向在 `A` 底下不變，
只被拉長 `λ` 倍。第 8 講的對角化就是把 `A` 拆成「在這些方向上各自伸縮」——
這題先用最笨的方式找出其中一個。

**冪迭代**：拿一個起始向量反覆餵給 `A`，每次重新單位化。

```
v₀ = v0 / ‖v0‖
v_{k+1} = A v_k / ‖A v_k‖
```

每輪算完新的 `v` 之後，用 **Rayleigh 商**估計特徵值（`v` 是單位向量，不用除 `vᵀv`）：

```
λ_k = v_kᵀ A v_k
```

實作 `power_iteration(A, v0, iters)`，**固定跑 `iters` 輪**，回傳四個元素：

```
( lam,     ← 最後一輪的 λ，也就是 lams[-1]
  v,       ← 跑完 iters 輪的單位向量，符號正規化過（見下）
  lams,    ← 長度 iters 的 list，第 k 個是第 k 輪之後的 λ
  resid )  ← ‖A v − lam · v‖，歐式長度
```

**符號正規化**：`v` 和 `−v` 是同一個方向，為了讓答案唯一，
回傳前把 `v` 調成「絕對值最大的分量為正」（並列時取索引最小的）。
`lam` 和 `resid` 不受 `v` 的符號影響，正規化放最後做就好。

**範例**

```python
power_iteration([[2, 0], [0, 1]], [1, 1], 20)
# -> ( 2.0, [1.0, 9.537e-07], [...], 9.537e-07 )
power_iteration([[2, 1], [1, 2]], [1, 0], 30)
# -> ( 3.0, [0.7071067812, 0.7071067812], [...], ~1e-15 )
power_iteration([[-3, 0], [0, 1]], [1, 1], 30)
# -> ( -3.0, [1.0, 0.0], [...], ~2e-14 )
```

第三個例子的主特徵值是**負的**。`v` 每一輪都翻一次面，但 `λ` 始終是 −3。
這就是為什麼用 Rayleigh 商而不是 `‖A v‖ / ‖v‖`——後者只告訴你 `|λ|`。

## 這題真正要你看到的是它什麼時候不管用

注意規格是「固定跑 iters 輪」，不是「跑到收斂」。
這個函式只照公式跑完然後回報，**它不保證收斂**——測資裡有四種收不了的情況：

- `v0` 恰好垂直於主特徵向量：`lams` 從第一輪就卡在次要特徵值不動
- `|λ₁| = |λ₂|`：`v` 在兩個向量之間來回跳，永遠不停
- `λ₂/λ₁` 接近 1：會收斂，但慢到看起來像不會
- `A` 不可對角化（重根但特徵向量不夠）：會收斂，但慢成 `O(1/k)`

把 `lams` 整個印出來對照。`[[2,0],[0,1]]` 約十輪就到小數第六位，
`[[2,0],[0,1.9]]` 跑三十輪還在小數第三位晃——主特徵值都是 2，
差別只在第二大的那個。那個比值決定一切，是 M0.5 和 M0.6 的伏筆。

**限制**
- `1 <= n <= 50`，`1 <= iters <= 200`
- `A` 是 n×n，元素是整數或浮點數，**不保證對稱**
- 保證 `‖A v_k‖` 不會是 0
- **不要用 numpy**
- `lams` 要每一輪真的記一次，不要算完最後一個再複製 `iters` 份
- 數值比對容差 `1e-9`
