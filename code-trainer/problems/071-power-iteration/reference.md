# 071-power-iteration · 冪迭代找主特徵值 — 參考解

## 標準解

```python
def power_iteration(A, v0, iters):
    n = len(A)

    def matvec(u):
        return [sum(A[i][j] * u[j] for j in range(n)) for i in range(n)]

    def norm(u):
        return sum(t * t for t in u) ** 0.5

    v = [t / norm(v0) for t in v0]

    lams = []
    for _ in range(iters):
        w = matvec(v)
        wn = norm(w)
        v = [t / wn for t in w]                 # 單位化：把 λ₁^k 的倍率丟掉
        Av = matvec(v)
        lams.append(sum(v[i] * Av[i] for i in range(n)))   # Rayleigh 商

    k = max(range(n), key=lambda i: (abs(v[i]), -i))       # 絕對值最大、並列取小索引
    if v[k] < 0:
        v = [-t for t in v]

    lam = lams[-1]
    Av = matvec(v)
    resid = sum((Av[i] - lam * v[i]) ** 2 for i in range(n)) ** 0.5
    return (lam, v, lams, resid)
```

`(abs(v[i]), -i)` 這個 key 是個值得記住的小技巧：tuple 比較是逐項的，
所以主鍵是 `abs(v[i])` 由大到小，平手時比 `-i`——索引小的 `-i` 比較大，就贏了。

## 為什麼它會收斂

設 `A` 可對角化，特徵向量 `x₁ … xₙ`、特徵值 `|λ₁| > |λ₂| >= … >= |λₙ|`。
任何起始向量都能展開成 `v0 = Σᵢ cᵢxᵢ`，而

```
A^k v0 = Σᵢ cᵢ λᵢ^k xᵢ = λ₁^k ( c₁x₁ + Σ_{i>=2} cᵢ (λᵢ/λ₁)^k xᵢ )
```

只要 `|λᵢ/λ₁| < 1`（`i >= 2`），括號裡的尾項全部指數衰減，方向趨近 `x₁`。
每一輪的單位化把 `λ₁^k` 丟掉——那個倍率可能爆炸（`|λ₁| > 1`）或消失（`|λ₁| < 1`），
但它不影響方向，所以丟掉剛好。

**收斂率**：方向的誤差大約是 `O(|λ₂/λ₁|^k)`。
而 Rayleigh 商有個額外的好處：對**對稱**矩陣，它的誤差是方向誤差的**平方**，
也就是 `O(|λ₂/λ₁|^(2k))`。這是為什麼要用 `vᵀAv` 而不是別的估計方式——它免費多賺一倍精度。
（非對稱矩陣沒有這個平方效果，只有一次方。）

對照測資：`[[2,0],[0,1]]` 的比值是 0.5，要讓 `0.5^(2k) < 1e-6` 得 `k ≈ 10`
→ 實測正好十輪，對得上。
`[[2,0],[0,1.9]]` 的比值是 0.95，要 `0.95^(2k) < 1e-6` 得 `k ≈ 135`
→ 三十輪當然還差得遠。

## 四種失效，以及它們在測資的哪裡

**1. `c₁ = 0`（起點垂直於主特徵向量）** — `[[2,0],[0,1]]`、`v0 = [0,1]`。
第一項根本不存在，於是收斂到 `λ₂ = 1`。注意 `resid` 是 0：
它**是**一個完全合法的特徵對，只是不是主的那個。

**2. `|λ₁| = |λ₂|`** — `[[0,1],[1,0]]`、`v0 = [2,1]`。
特徵值是 ±1，`v` 在兩個向量之間來回跳，`lams` 每一輪都是 0.8，永遠不動。
這種情況**無解**，不是迭代次數不夠。

**3. 比值接近 1** — `[[2,0],[0,1.9]]`。會收斂，只是 `0.95^(2k)` 慢得看不出來。

**4. 不可對角化** — `[[3,1],[0,3]]`。重根 3，但只有一個特徵向量
（幾何重數 1 < 代數重數 2）。上面那個展開式**本身不成立**，
要用 Jordan 形式，衰減從指數退化成 `O(1/k)`。跑 50 輪還在 3.056。

第 1 種在實務上其實不太危險：浮點誤差會讓 `c₁` 從精確的 0 變成 `1e-17`，
然後它以 `(λ₁/λ₂)^k` 的速度長回來。**所以真實的程式都用隨機起始向量**——
隨機向量垂直於 `x₁` 的機率是 0。這題固定給 `v0`，純粹是為了測資能寫死答案。

第 2 種才是真正無解的那個。對稱矩陣不會遇到嗎？會：
`[[0,1],[1,0]]` 就是對稱的。對稱只保證特徵值是實數、特徵向量正交，
**不保證絕對值不相等**。

## 複雜度

- 時間 **O(iters · n²)**：每輪兩次矩陣乘向量，各 `n²` 次乘加
- 空間 **O(n + iters)**：幾個長度 n 的向量，加上 `lams`

每輪兩次 matvec 可以省成一次（在單位化**之前**用 `λ = v·w / (v·v)`，
那是上一輪的 `v` 的 Rayleigh 商）。但那樣 `lams` 的定義就位移一格，
而且省下的只是常數倍。`n` 很大時真正的做法是 Lanczos / Arnoldi，不是省這一次。

## 常見錯誤

1. **用 `‖Av‖ / ‖v‖` 當特徵值** — 它等於 `|λ|`，符號掉了。
   `[[-3,0],[0,1]]` 那筆會得到 `+3`。這是這題最想抓的錯。
2. **Rayleigh 商算在更新 `v` 之前** — `lams` 整串往前位移一格，最後一個也錯。
   `[[4,1],[2,3]]` 那筆的 `lams[0]` 恰好是 5.0，會讓你以為沒錯。
3. **忘了每輪單位化** — 只在最後單位化一次。`|λ₁| > 1` 時 `A^k v0` 會溢出成 `inf`，
   `|λ₁| < 1` 時會變成 0。迭代法每一步都要重新正規化，這是通則。
4. **符號正規化挑錯分量** — 挑「第一個非零」而不是「絕對值最大」。
   浮點數下「非零」沒有明確意義（`1e-17` 算不算？），所以規格挑的是絕對值最大的那個，
   它在數值上穩定。
5. **並列時取錯索引** — key 只寫 `abs(v[i])`，平手時 `max` 回傳**先遇到**的，
   在 Python 裡剛好也是小索引，所以這個錯不會現形。但別依賴它，寫清楚。
6. **`lams` 只算最後一個再乘 `iters`** — 前幾筆測資的 `lams` 是遞增的，立刻抓到。

## 延伸

M0.4 還有一題，會走對角化與對稱矩陣譜定理那條線。

冪迭代本身是一整個家族的起點：

- **反冪迭代**：對 `A⁻¹` 做冪迭代 → 找**最小**特徵值。
  SLAM 裡求最小奇異值的方向（例如求基礎矩陣的零空間）用的就是這個。
- **移位反冪迭代**：對 `(A − σI)⁻¹` 做 → 找最靠近 `σ` 的那個特徵值。
- **Rayleigh quotient iteration**：每輪用當前的 Rayleigh 商當移位量，三次收斂。
- **QR 演算法**：`np.linalg.eig` 真正在跑的東西。它是「同時對所有特徵向量做冪迭代」，
  而裡面正交化那一步，就是你在 060 手寫的 Gram-Schmidt。

**跟你的方向的關係**：

- **M0.5 SVD**：`A` 的奇異值是 `AᵀA` 特徵值的平方根。對 `AᵀA` 做冪迭代
  就得到第一個主成分——那正是 PCA 的第一主成分，也是 PageRank 的原型。
- **最佳化的步長**：梯度下降能用多大的學習率，由 Hessian 的**最大**特徵值決定；
  收斂多慢，由最大與最小的**比值**（條件數，M0.6）決定。
  所以 Gauss-Newton 的實作裡常常偷偷跑幾輪冪迭代去估那個最大值。
- **相機姿態**：3D 旋轉矩陣的特徵值是 `1`、`e^(iθ)`、`e^(−iθ)`。
  特徵值 1 對應的特徵向量就是**旋轉軸**——
  M00.5 你算過旋轉與複數，那時候的 `θ` 現在有了代數上的來源。
