# 065-project-onto-subspace · 投影到一個子空間 — 參考解

## 標準解

```python
def project_onto(basis, v):
    def dot(a, b):
        return sum(x * y for x, y in zip(a, b))

    Q = []                                        # 060 的 Gram-Schmidt
    for u in basis:
        w = [float(x) for x in u]
        for q in Q:
            c = dot(q, u)
            w = [wi - c * qi for wi, qi in zip(w, q)]
        length = dot(w, w) ** 0.5
        Q.append([wi / length for wi in w])

    def proj(x):                                  # 各方向分量相加
        out = [0.0] * len(x)
        for q in Q:
            c = dot(q, x)
            for i in range(len(x)):
                out[i] += c * q[i]
        return out

    p = proj(v)
    r = [float(a) - b for a, b in zip(v, p)]
    dots = [dot(r, b) for b in basis]
    return p, r, dots, proj(p)
```

時間 O(k² n)（Gram-Schmidt 主導），空間 O(kn)。

## 為什麼可以逐方向相加

設 `p = Σᵢ cᵢ qᵢ`，我們要的是「讓 `v − p` 垂直於整個子空間」。
垂直於整個子空間 ⟺ 垂直於每個 `qⱼ`（因為子空間裡的任何向量都是 q 的組合）。所以

```
qⱼ · (v − Σᵢ cᵢ qᵢ) = 0
qⱼ·v − Σᵢ cᵢ (qⱼ·qᵢ) = 0
```

**q 們正交單位**，所以 `qⱼ·qᵢ` 只有 `i = j` 那項是 1，其他都是 0：

```
qⱼ·v − cⱼ = 0     →     cⱼ = qⱼ·v
```

k 個方程式各自獨立解出一個係數，**完全沒有交互項**。

基底不正交的話，`qⱼ·qᵢ` 不是 0，k 個方程式就糾纏在一起，變成要解一個 k×k 的線性系統——
那就是下一題的 **normal equation**。Gram-Schmidt 的價值就是把那個系統對角化掉。

## 為什麼 p 是最近的點

取子空間裡任何其他點 `y`。因為 `p − y` 在子空間裡、`v − p` 垂直於子空間：

```
|v − y|² = |(v − p) + (p − y)|² = |v − p|² + |p − y|²
```

中間的交叉項 `2(v−p)·(p−y)` 是 0。所以 `|v − y|² ≥ |v − p|²`，等號只在 `y = p` 時成立。

**這就是畢氏定理。** 「投影 = 最近點」不是定義，是垂直性推出來的結果——
而這件事是整個最小平方法的地基：下一題要找的「最能擬合資料的直線」，
就是把資料向量投影到「所有可能的直線」張成的子空間上。

## 為什麼 P² = P

`p` 已經在子空間裡了。對子空間裡的向量做投影，殘差是零向量，投影就是自己。
所以 `proj(proj(v)) = proj(v)`。

這個性質叫**冪等**，寫成矩陣是 `P² = P`。反過來也成立：**任何滿足 `P² = P` 的矩陣都是投影矩陣**——
它的行空間是被投影到的子空間，零空間是被砍掉的方向。這兩個空間垂直（如果還滿足 `Pᵀ = P`），
正是 061 那張四個基本子空間的表。

投影矩陣的其他性質，可以自己驗證：

| 性質 | 意思 |
|---|---|
| `P² = P` | 冪等 |
| `Pᵀ = P` | 對稱（正交投影才有；斜投影不對稱） |
| 特徵值只有 0 和 1 | 子空間裡的方向乘 1、垂直的方向乘 0（M0.4 會回來看） |
| `rank(P) = k` | 等於子空間的維度 |
| `I − P` 也是投影 | 投影到**正交補**，也就是殘差的方向 |

## 另一種寫法：投影矩陣的閉式解

把 basis 當成**行**排成矩陣 `A`（n×k），那麼

```
P = A (AᵀA)⁻¹ Aᵀ
p = P v
```

這是課本公式，下一題會用到它的變形。它不需要 Gram-Schmidt，但要算一個 k×k 的反矩陣。

**實務上不用這個公式**：`AᵀA` 的條件數是 `A` 的平方，數值上比 QR 差很多（M0.6 會量化這件事）。
`np.linalg.lstsq` 底層用 QR 或 SVD，不會去算 `(AᵀA)⁻¹`。

基底正交時 `AᵀA = I`，公式退化成 `P = A Aᵀ`——就是你寫的逐方向相加。

## 常見錯誤

1. **沒正交化就直接相加**——`basis = [[1,0], [1,1]]`、`v = [0,1]` 會得到 `[0.5, 0.5]` 而不是 `[0, 1]`。
   重疊的成分被算了兩次。這是這題唯一的核心陷阱。

2. **`dots` 用正交化後的 Q 算**——那當然是 0，但沒驗證到你的 `p` 對不對。
   要用**原始 basis**，這樣「殘差垂直於整個子空間」才是真的被檢查了。

3. **`p2` 直接回傳 `p`**——測資會過，但冪等性就沒被驗證。

4. **投影係數用未正規化的基底**——如果沒把 q 除以長度，係數要寫成 `dot(q,v)/dot(q,q)`。
   混用兩種寫法（正規化了又除一次，或沒正規化也沒除）是常見的錯。

5. **累加時覆蓋而不是累加**——`out[i] = c * q[i]` 少了 `+`，只會留下最後一個方向的貢獻。

## 延伸

- **下一題**：把「投影」換成「用直線擬合一堆資料點」。那是同一件事——
  最小平方就是投影，殘差垂直就是 normal equation。
- **M0.5 SVD**：`U U ᵀ` 是投影到行空間，SVD 讓你一眼看出投影到「前 r 個主要方向」會丟掉多少。
  那就是低秩近似與 PCA。
- **M2.x SLAM**：bundle adjustment 每次迭代都在解一個最小平方問題，
  而 Schur complement（消掉地圖點只留相機姿態）本質上是一次投影。
- **CV 的 RANSAC**：每次取樣之後 fit 一個模型，那個 fit 通常就是最小平方投影。
