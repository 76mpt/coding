# 065-project-onto-subspace · 投影到一個子空間

- 階段：數學基礎（Tier 0：沒有就寸步難行） / M0.3 投影與最小平方
- 語言：Python　難度：warmup　互動方式：實作函式

- 提示：共 4 階（`python trainer.py hint 065-project-onto-subspace`）
- 測資：9 筆（`python trainer.py test 065-project-onto-subspace`）

────────────────────────────────────────────────────────────────────

030 你把 `v` 投影到**一個向量**上，殘差跟那個向量垂直。
這題把它推廣：投影到**一整個子空間**——由好幾個向量張成的那個空間。

060 的 Gram-Schmidt 已經把難的部分做完了。如果子空間有一組**正交單位**基底 `q₁ … q_k`，
投影就是把每個方向的分量加起來：

```
p = (q₁·v) q₁ + (q₂·v) q₂ + … + (q_k·v) q_k
```

每一項都是 030 那個投影。**因為 q 們互相垂直，各方向的分量互不干擾，可以直接相加**——
這正是為什麼要先正交化。基底不正交的話不能這樣加。

實作 `project_onto(basis, v)`，回傳一個 tuple，四個元素：

```
( p,       ← v 投影到 basis 張成的子空間上
  r,       ← 殘差 v − p
  dots,    ← r 跟「每個原始基底向量」的內積
  p2 )     ← 把 p 再投影一次的結果
```

`basis` 是 k 個長度 n 的向量、**保證線性獨立**（但不保證正交）；`v` 長度 n。所有數值回傳 float。

**範例**

```python
project_onto([[1, 0, 0], [0, 1, 0]], [3, 4, 5])
# -> ( [3.0, 4.0, 0.0],      投影到 xy 平面：把 z 砍掉
#      [0.0, 0.0, 5.0],      殘差只剩 z 分量
#      [0.0, 0.0],           殘差跟 (1,0,0)、(0,1,0) 都垂直
#      [3.0, 4.0, 0.0] )     再投影一次沒有變化
```

## 這題真正要你看到的東西

兩件事同時成立，它們是投影的完整定義：

- **`dots` 全是 0**：殘差垂直於整個子空間。`p` 是子空間裡**離 v 最近**的點——
  任何其他點到 v 的距離都更遠（畢氏定理：多繞的那一段跟殘差垂直，斜邊更長）
- **`p2 == p`**：投影兩次等於投影一次。`p` 本來就在子空間裡了，再投影不會動它

寫成矩陣就是 **`P² = P`**，這叫**冪等（idempotent）**。
它是「投影」這個詞的代數定義——任何滿足 `P² = P` 的矩陣都是某個子空間上的投影。

**限制**
- `1 <= k <= n <= 5`，元素是整數，基底保證線性獨立且離相依很遠
- **不要用 numpy**
- `dots` 要用**原始的** basis 算，不是正交化之後的 q——那才驗證得到東西
- `p2` 要真的再跑一次投影，不要直接回傳 `p`。測資一樣會過，但那樣就沒驗證冪等性
