# 022-entropy · 熵：換底與 0 log 0

**熵（entropy）** 衡量一個機率分布的「不確定性」。定義是：

```
H(p) = − Σᵢ pᵢ · log_b(pᵢ)
```

實作 `entropy(probs, base=2)`，`base` 是對數的底（預設 2，單位是 bit）。

**範例**

```
entropy([0.5, 0.5])           ->  1.0
```

公平銅板：兩個結果各 0.5。`−(0.5·log₂0.5 + 0.5·log₂0.5) = −(−0.5 −0.5) = 1`。
**丟一次公平銅板剛好給你 1 bit 的資訊**——這就是 bit 這個單位的來源。

```
entropy([1.0])                ->  0.0      # 必然發生，沒有不確定性
entropy([0.25]*4)             ->  2.0      # 四個等機率結果 = 2 bits
entropy([0.5, 0.25, 0.25])    ->  1.5
entropy([0.9, 0.1])           ->  0.4689955935892812   # 很偏的分布，熵低
entropy([0.5, 0.5], base=math.e)  ->  0.6931471805599453   # 單位變成 nat
```

**兩個必須處理的細節**

1. **`0 log 0` 定義為 0。**
   數學上 `lim_{p→0} p·log p = 0`，所以機率為 0 的結果對熵沒有貢獻。
   但程式裡 `math.log(0)` 會直接拋 `ValueError`，所以你要自己跳過。
   `entropy([1.0, 0.0])` 必須是 `0.0`，不能爆炸。

2. **換底。** `math.log(x, base)` 可以直接指定底，
   但你也應該知道換底公式 `log_b(x) = ln(x) / ln(b)` 是怎麼回事。

**限制**
- `probs` 的元素在 `[0, 1]`，總和約為 1（不需要你檢查或正規化）。
- `probs` 可能是空 list，這時回傳 `0.0`。
- `base > 1`。
- 判定使用近似比較。
