# 035-det-and-area · 行列式與面積縮放 — 參考解

## 標準解

```python
def det_and_area(M):
    (a, b), (c, d) = M
    det = a * d - b * c

    u = (a, c)      # (1,0) 的像 —— M 的第一行
    v = (b, d)      # (0,1) 的像 —— M 的第二行
    area = abs(u[0] * v[1] - u[1] * v[0])

    return det, area
```

`(a, b), (c, d) = M` 是**巢狀解包**：外層把 M 拆成兩列，內層再把每列拆成兩個數。
一行取代四次 `M[i][j]`，而且名字直接對應公式。

## 為什麼 area 展開後就是 |det|

```
area = | u₀v₁ − u₁v₀ |
     = | a·d − c·b |
     = | ad − bc |
     = | det |
```

**兩個式子完全相同。** 這就是這題的全部內容——`ad − bc` 不是一個要背的公式，
它**就是**「兩個基底向量張成的平行四邊形面積」。

那為什麼還要分開算？因為**你得自己看到它們相等**。
直接寫 `area = abs(det)` 的話，你只是複述了一遍公式，沒有驗證任何東西。
這跟 M00.2 的「殘差與 b 正交」是同一種手法：**用一個獨立的路徑得到同一個數字**。

## 為什麼是「行」不是「列」

```
M @ (1, 0) = (a·1 + b·0,  c·1 + d·0) = (a, c)     ← M 的第一行
M @ (0, 1) = (a·0 + b·1,  c·0 + d·1) = (b, d)     ← M 的第二行
```

**矩陣的每一「行」就是那個基底向量變換後的落點。** 這是「看懂矩陣」最重要的一句話：

> 想知道一個矩陣在做什麼，就看它把 `(1,0)` 和 `(0,1)` 送到哪裡。

3B1B《線性代數的本質》EP3 整集在講這件事（你剛看完的 EP6 講的就是行列式）。

## 三個特殊情況的意義

| M | det | 面積 | 幾何 |
|---|---|---|---|
| `[[1,1],[0,1]]` | 1 | 1 | **推移（shear）**：正方形歪成平行四邊形，但底和高沒變，所以面積不變 |
| `[[0,1],[1,0]]` | **−1** | 1 | **翻轉**：把平面翻面了。負號記錄「換手性」，面積本身不變 |
| `[[1,2],[2,4]]` | **0** | 0 | **退化**：兩行成比例（`(2,4) = 2×(1,2)`），平面被壓成一條線 |

**`det = 0` ⟺ 不可逆。** 壓扁之後資訊就沒了，沒有任何矩陣能把一條線還原成一個平面。

而「離 0 有多近」是個實務問題——`det = 1e-15` 在數學上可逆，在浮點世界等於不可逆。
**M0.6 的條件數就是在量這件事**，而且它比 det 更可靠（det 會隨矩陣縮放而劇烈變化，條件數不會）。

## 常見錯誤

1. **`area = abs(det)`** —— 會過測資，但完全繞過了這題的目的。你沒有驗證到任何東西。
2. **用「列」當基底向量的像** —— 寫成 `u = (a, b)`、`v = (c, d)`。這算的是 `det(Mᵀ)`，而 **`det(Mᵀ) = det(M)`**，所以⋯⋯**測資全部會過**。這是這題最陰險的地方：寫錯了也看不出來，但你對「矩陣的行是什麼」的理解是錯的，到 M0.1 線性映射就會撞牆。
3. **面積忘記取絕對值** —— `[[0,1],[1,0]]` 會回傳 `-1`。面積是幾何量，不能是負的。
4. **det 也取了絕對值** —— 那就丟掉「有沒有翻面」的資訊了。測資 `[[0,1],[1,0]]` 期望 det 是 `-1`。
5. **公式記成 `ac − bd`** —— 對角線相乘，不是同列或同行相乘。畫一次 `X` 就不會錯。

## 延伸

行列式在後面幾乎都是以「**體積縮放倍率**」的身分出現，而不是靠它的計算公式：

| 節點 | 行列式在做什麼 |
|---|---|
| **M0.4** 特徵值 | `det(A − λI) = 0` 就是特徵方程式 |
| **M0.6** 條件數 | det 接近 0 = 病態；但條件數是更好的度量 |
| **M2.7** 旋轉表示 | 旋轉矩陣的 `det = +1`（保持體積、不翻面）。`det = −1` 的是鏡射，**不是合法的旋轉** |
| **M5.5** 正規化流 | 換元積分的 Jacobian 行列式——機率密度怎麼隨變換伸縮 |

**M2.7 那條特別重要**：判斷一個 3×3 矩陣是不是合法的旋轉，就是檢查 `RᵀR = I` 且 `det(R) = +1`。
少檢查 det 的話，你會把鏡射誤當成旋轉——那在 SLAM 裡是會讓整個軌跡翻過來的 bug。
