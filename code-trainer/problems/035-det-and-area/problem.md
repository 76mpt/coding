2×2 矩陣的行列式：

```
      | a  b |
det   | c  d |   =  ad − bc
```

計算公式兩秒就記得了。**但它的幾何意義才是重點：**

> `|det(M)|` 就是「**單位正方形經過 M 變換之後的面積**」。

單位正方形的四個角是 `(0,0), (1,0), (1,1), (0,1)`。把它們各自乘上 M，
會得到一個平行四邊形——**它的面積就是 `|det(M)|`**。

實作 `det_and_area(M)`，回傳 `(det, 變換後的面積)`：

1. `det` 用公式 `ad − bc` 算，**可以是負的**。
2. 面積是**單位正方形變換後的實際面積**，用**兩個邊向量的叉積大小**算出來——
   **不要直接回傳 `abs(det)`**，那樣就沒驗證到任何東西。

**怎麼算變換後的面積**

矩陣 `M = [[a, b], [c, d]]` 把兩個基底向量送到：

```
(1, 0)  →  (a, c)      ← M 的第一「行」
(0, 1)  →  (b, d)      ← M 的第二「行」
```

這兩個向量張成的平行四邊形，面積 = **二維叉積的絕對值**：

```
area = |u₀ v₁ − u₁ v₀|      其中 u = (a, c)、v = (b, d)
```

**範例**

```python
det_and_area([[1, 0], [0, 1]])   ->  (1, 1)     # 單位矩陣，什麼都沒變
det_and_area([[2, 0], [0, 3]])   ->  (6, 6)     # x 拉 2 倍、y 拉 3 倍 → 面積 6 倍
det_and_area([[1, 1], [0, 1]])   ->  (1, 1)     # 推移(shear)：形狀歪了，面積不變
det_and_area([[0, 1], [1, 0]])   ->  (-1, 1)    # 翻轉：det 是負的，面積還是 1
det_and_area([[1, 2], [2, 4]])   ->  (0, 0)     # 退化：壓成一條線，面積 0
```

**負的 det 是什麼意思**

`det < 0` 代表這個變換**把平面翻面了**（左手變右手）。面積是幾何量所以永遠 ≥ 0，
但 det 保留了「有沒有翻面」這個資訊——這就是為什麼題目要你兩個都回傳。

**`det = 0` 是什麼意思**

整個平面被壓扁成一條線（或一個點），面積歸零。這代表 **M 不可逆**——
資訊被壓掉了，救不回來。之後 M0.6 的「條件數」就是在量「離這個災難有多近」。

**限制**
- `M` 一定是 2×2，元素是 int 或 float。
- 判定使用近似比較，容差約 10⁻⁹。
- 回傳 tuple 或 list 都可以。
